# Портфолио Николая Карпова

[![Deployed via GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-deployed-blue?logo=github)](https://nikolai-karpov.github.io)

Простое, но продуманное портфолио, построенное на чистом HTML и CSS, с использованием современных подходов к структуре и поддержке контента. Основная цель — показать методологию работы и реальные кейсы с акцентом на ясность и удобство восприятия.

---

## 🎯 Цель проекта

Представить:
- Философию и методологию работы
- Практические кейсы из профессионального опыта
- Аналитический подход к решению задач

---

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — кастомные стили, адаптивная верстка
- **Fetch API** — динамическая подгрузка шапки и подвала (`header.html`, `footer.html`)
- **GitHub Pages** — хостинг

> Нет внешних библиотек и фреймворков — только чистый код для максимальной производительности и контроля.

## 🏗️ Архитектурные принципы

### 🧱 Архитектура BEM:
- Используется для компонентов: `.card--competency`, `.card__icon`, `.card__metric`
- Четкое разделение на блоки, элементы и модификаторы
- Упрощает поддержку и переиспользование

### 🎨 Цветовая палитра:
- `--primary-color: #4A90E2` (синий)
- `--gradient-primary: linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
- `--dark-color: #2c3e50` (темный)
- `--light-bg-color: #f8f9fa` (светлый фон)
- `--neural-glow: rgba(74, 144, 226, 0.1)` (нейросвечение)

### 📏 Отступы:
- `--spacing-xs: 8px`
- `--spacing-sm: 16px`
- `--spacing-md: 24px`
- `--spacing-lg: 32px`
- `--spacing-xl: 48px`

### 🎭 Анимации и интерактивность:
- `@keyframes float` - плавание карточек
- `@keyframes rotate` - вращение рамки
- `@keyframes pulse` - пульсация
- `@keyframes fadeIn` - плавное появление
- `data-aos` - анимации при скролле

### 📱 Адаптивные breakpoints:
- `max-width: 480px` - мобильные
- `max-width: 768px` - планшеты
- `max-width: 992px` - маленькие десктопы
- `max-width: 1200px` - средние десктопы

### 📚 Типографика:
- **Font Family**: Inter, fallback: -apple-system
- **Font Sizes**:
    - `--font-size-4xl: 3rem` (48px)
    - `--font-size-3xl: 2rem` (32px)
    - `--font-size-2xl: 1.5rem` (24px)
    - `--font-size-xl: 1.25rem` (20px)
- **H1**: `var(--font-size-4xl)`
- **H2**: `var(--font-size-3xl)`
- **H3**: `var(--font-size-2xl)`

### 🛠️ Система компонентов:
- **Карточки**: reusable компоненты
- **Кнопки**: иерархия primary/secondary
- **Формы**: consistent styling
- **Секции**: стандартизированные отступы
- **Контейнеры**: центрирование и ограничение ширины

## 🔧 Как работает подгрузка header/footer?

```javascript
// Загрузка шапки
fetch('components/header.html')
  .then(response => response.text())
  .then(data => {
    document.getElementById('header').innerHTML = data;
  });

// Загрузка подвала
fetch('components/footer.html')
  .then(response => response.text())
  .then(data => {
    document.getElementById('footer').innerHTML = data;
  });
```


> Это позволяет легко поддерживать единый дизайн по всему сайту без использования серверных технологий.
