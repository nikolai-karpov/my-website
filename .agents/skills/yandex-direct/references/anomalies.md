# Интерпретация аномалий + intent verification

`yandex_direct_anomalies` возвращает кампании с |Δ| > порога. Эта страница помогает агенту не пугать пользователя ложными тревогами и формулировать конкретные рекомендации.

## Intent verification: настоящая проблема vs нормальный шум

Перед формулированием тревоги пройди по чек-листу:

| Сигнал | Это шум, не упоминать | Это реальная проблема |
|---|---|---|
| Δ% при малом базовом значении (impressions < 100) | ✓ — игнорировать | ✗ |
| Один день перекосил неделю (праздники, выходной) | ✓ — отметить и не тревожить | ✗ |
| Сдвиг внутри RU-бенчмарка (см. [[benchmarks]]) | ✓ — «вернулось к норме» | ✗ |
| Сдвиг направлен в **хорошую** сторону (CTR ↑, CPC ↓, конверсии ↑) | Стоит упомянуть, но не как тревогу | ✗ |
| Cost ↑↑ при Conversions стабильно или ↑ | ✗ | ✓ — реальная проблема |
| Conversions ↓↓ при Clicks ≈ stable | ✗ | ✓ — сломалась воронка |
| CPC ↑↑ при Clicks ↓↓ (двойной негатив) | ✗ | ✓ — аукцион перегрелся |
| Impressions = 0 в новой кампании | ✗ | ✓ — проверить модерацию |

**Red flag для intent**: если **все** «аномалии» в выгрузке — шум (низкие базы, бенчмарк-нейтральные сдвиги), скажи прямо: «За неделю всё стабильно, заметных проблем нет». Не выдавливай из себя три рекомендации, если их нет.

## Паттерны сдвигов → причины → рекомендации

| Паттерн | Вероятная причина | Что рекомендовать |
|---|---|---|
| Impressions ↓↓, Clicks ↓↓, CTR ≈ stable | Кампания на паузе / упёрлась в дневной бюджет / просели позиции | Проверить state/budget в `yandex_direct_campaigns`; поднять дневной лимит или CPC |
| CTR ↓↓ при стабильных Impressions | Креатив выгорел; новый конкурент с лучшим текстом; ухудшилось качество фразы | Обновить заголовки/тексты, посмотреть выдачу глазами |
| CPC ↑↑ резко | Аукцион нагрелся; сняли лимит ставки; новые конкуренты в нише | Сравнить с Wordstat (когда подключим); временно снизить ставку или сузить геотаргетинг |
| Cost ↑↑ при стабильных Clicks | CPC растёт без отдачи | Аудит ключей через `yandex_direct_keywords`, найти дорогие нерелевантные |
| Conversions ↓↓ при стабильных Clicks | Сломалась цель в Метрике / лендинг лежит / трафик стал мусорным | Проверить Метрику (`yandex_metrika_conversions`), `SEARCH_QUERY_PERFORMANCE_REPORT` |
| `top_delta_is_new: true` | Метрика появилась с нуля — новая кампания или возобновили | Не тревога — пометить как "new campaign" |
| Конверсии ↑↑ при Cost ≈ stable | Креатив зашёл / новая аудитория / снизился CPA | Зафиксировать, что работает — расширить бюджет |

## Формат подачи

Всегда показывай **обе цифры** + Δ%:

```
«Бренд / Москва»: CPC 8.20 ₽ → 12.10 ₽ (+47%) при тех же кликах (1 280 vs 1 245).
```

Проценты без абсолютных значений вводят в заблуждение на малых базах: «-100% Conversions» при 1→0 ничего не значит.

## Если нечего сказать

«За период с X по Y значимых сдвигов не нашёл. Все кампании в пределах своих обычных колебаний, расход в норме».

— это **корректный и нужный ответ**, не дефект работы.
