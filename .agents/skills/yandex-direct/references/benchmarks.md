# Benchmarks RU-рынка

Типичные диапазоны метрик для интерпретации абсолютных значений. **Аномалии — это сдвиг относительно собственной истории кампании, а не отклонение от рынка**. Эта таблица — чтобы не пугать пользователя цифрами, которые на самом деле в норме.

| Метрика | Поиск | РСЯ (YAN) |
|---|---|---|
| CTR | 5–8% | 0.3–0.8% |
| CPC | 30–150 ₽ | 5–30 ₽ |
| CVR (конверсия в цель) | 2–5% | 0.5–2% |

## Как использовать

- CTR Поиска 9% → отличный показатель, **не аномалия**, даже если на 30% выше прошлой недели.
- CTR РСЯ 0.4% → норма, не «провал».
- CPC поискового бренда 5–15 ₽ — нормально для брендовых запросов (низкая конкуренция).
- CPC поискового конкурентного запроса 200+ ₽ — норма для дорогих ниш (юр.услуги, недвижимость, медицина).
- CVR 7–10% Поиска для микро-цели (просмотр контакта) — норма.

## Когда отклонение от бенчмарка стоит упомянуть

- CTR Поиска < 3% → проблема (плохой текст, нерелевантный ключ).
- CTR РСЯ > 2% → подозрительно (накрутки, фрод).
- CPC выше топ-границы в 2× → перегретый аукцион, имеет смысл сузить геотаргетинг.
