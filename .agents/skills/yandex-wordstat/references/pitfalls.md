# Wordstat (Search API) — подводные камни и интерпретация

## API-механика

- **Авторизация — `Api-Key`, не OAuth.** Заголовок `Authorization: Api-Key <секрет>`. Секрет (`AQVN...`) показывается один раз при создании ключа в AI Studio. Если окно закрыто — секрет не восстановить, нужен новый ключ.
- **`folderId` обязателен в теле каждого запроса** — это идентификатор каталога Yandex Cloud, где живёт сервисный аккаунт ключа. Не путать с идентификатором самого ключа (`aje...`, нужен только для управления).
- **`count` приходит строкой**, не числом (`"276"`). Инструмент уже приводит к int — но если ходишь в API напрямую, не забудь `int()`.
- **Операторы поддерживаются ограниченно.** `topRequests` и `regions` поддерживают Wordstat-операторы (`+`, `!`, `[]`, кавычки). `dynamics` поддерживает все операторы только для daily; для weekly/monthly — только `+`. Для широкого сбора семантики начинай с чистой фразы, чтобы не сузить спрос случайно.
- **Device enum:** используй `DEVICE_ALL`, `DEVICE_DESKTOP`, `DEVICE_PHONE`, `DEVICE_TABLET`. `DEVICE_MOBILE` API отвергает.
- **Region type enum:** используй `REGION_CITIES` или `REGION_REGIONS`. `REGION_SUBJECTS` API отвергает.
- **Динамика по месяцам:** при `PERIOD_MONTHLY` в `toDate` нужен последний день месяца, иначе данные могут обрезаться.
- **Сравнение — по одной фразе за запрос.** Кластер собирается серией вызовов, не одним.
- **API бесплатен** в составе AI Studio (платно только за токены LLM, которых тут нет). Но есть лимиты по частоте — инструмент делает один ретрай на `429`.

## Интерпретация спроса (не обмануться)

- **Низкая частотность ≠ нет рынка.** Для узких B2B/enterprise-тем поисковый спрос почти всегда мал — ЛПР не гуглят «SRM для подрядчиков» каждый день. Низкий `total_count` означает, что **поиск — не главный канал**, а не что продукта не ждут. Вывод: не строить всю кампанию на поиске, использовать его точечно (бренд + узкогорячие запросы), а основной упор — на другие каналы.
- **Смотри, КУДА уводят смежные запросы.** Если `results`/`associations` к твоей фразе — «не про то» (напр. к «управление подрядчиками» липнет «1С финансы», «служба по контракту»), значит твоим смыслом эту фразу почти не ищут. Это сигнал переформулировать оффер на язык, которым реально ищут.
- **Горячий vs информационный спрос.** «купить / заказать / платформа / сервис» — горячий (готовы к решению). «как / что такое / проблема» — холодный (изучают). Под них разные сообщения.
- **`affinity` в регионах** > 100 = тема в этом регионе популярнее, чем в среднем по стране; полезно для гео-таргетинга даже при невысоком абсолюте.
- **Сезонность** ловится только на горизонте 12+ месяцев — короткое окно даёт шум.

## Региональные коды (частые)

- `225` — Россия, `1` — Москва и область, `213` — Москва, `2` — Санкт-Петербург, `3` — Центр.
- Остальное — через `yandex_wordstat_regions_tree({"search": "..."})`.
