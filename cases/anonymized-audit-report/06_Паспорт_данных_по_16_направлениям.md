# 06. Паспорт данных по направлениям внедрения

> **Цветовая индикация по итогам 7-недельного аудита.** Часть статусов — гипотезы (с пометкой ⓘ), требующие верификации после доделки белых пятен (см. раздел 10).

---

## Легенда

| Цвет | Статус | Что это значит |
|---------------|-----------------------------------------|------------------------------------------------------------------------------------------------------------------|
| 🟢 | Готово к пилоту | Данные есть, формат подтверждён, инфраструктура достаточна, лидер найден |
| 🟡 | Требует подготовки | Данные есть, но требуют нормализации/интеграции/анонимизации |
| 🔴 | Требуется инженерный проект | Данных нет в пригодном виде; нужна оцифровка / IIoT-дооснащение |
| 🔵 | Стратегическая платформа | Возможно после успешных пилотов Горизонтов 1–2 |
| ⓘ | Гипотеза | Требует подтверждения на доделке аудита |

## Горизонт 1. Готово к пилоту

### 1. Корпоративный советник / RAG по СТО, СМК, регламентам

- **Что даёт:** ответы на типовые вопросы за секунды, разгрузка HR/ОДО/руководителей. Снимает «дублирование вопросов годами».
- **Данные:** ~700 СТО, СМК, регламентов в Confluence + ELMA + сетевых ресурсах.
- **Готовность:** 🟢 после анонимизации (удаление имён, ФИО, юрлиц, брендов) — **согласовано на финальной встрече с ИБ**.
- **Условие старта:** анонимизатор на месте + векторная база + согласованный список «безопасных» документов.
- **Срок:** 4–6 недель.

### 2. HR-кабинет (рекрутинг)

- **Что даёт:** автоматизация формирования вакансий, скрининг резюме, мониторинг рынка зарплат, структурирование заявок на подбор.
- **Данные:** E-staff (внешние, не наши, не КТ), HH.ru (публичные).
- **Готовность:** 🟢 — **согласовано на финальной встрече, использовать внешний API**.
- **Срок:** 2–3 недели после согласования провайдера (DeepSeek / GigaChat / Яндекс GPT — на A/B).

### 3. ИИ-тренажёр продаж

- **Что даёт:** голосовой симулятор переговоров, отработка возражений, методология продаж.
- **Данные:** синтетические (методология Нила Рекхема и пр.) + публичные технические данные продуктов.
- **Готовность:** 🟢 — **согласовано на финальной встрече**. Есть готовая команда разработчиков (HR-направление).
- **Срок:** 4–6 недель.

### 4. Транскрибатор совещаний (БК + общие)

- **Что даёт:** автоматические протоколы, выделение задач, рассылка поручений. Снимает «потолок свободных рук» БК.
- **Данные:** аудиозаписи совещаний (внутренний контур, КТ).
- **Готовность:** 🟢 после ввода сервера. **Сервер ожидается в течение 2 недель**.
- **Срок:** 2–4 недели после ввода сервера.

### 5. Помощник аналитика ФЭД (перенос лимитов, сверка ЛК↔1С)

- **Что даёт:** автоматизация переноса лимитов между статьями (0,5 дня → секунды), сверка маркетплейсов с 1С (потери [сумма — NDA] зафиксированы).
- **Данные:** 1С + ЛК Ozon/WB + ELMA. Чувствительные.
- **Готовность:** 🟢 после ввода сервера. Внутренний эксперт назначен.
- **Срок:** 3–4 недели после ввода сервера.

### 6. Динамическое ценообразование (МВП на отдельных таблицах)

- **Что даёт:** анализ упущенной маржинальности по сегментам.
- **Данные:** история сделок (Excel-таблицы аналитика, нужно проверить структуру).
- **Готовность:** 🟢 ⓘ **после интервью с руководителем ДЦ** и подтверждения формата данных.
- **Срок:** 3–5 месяцев (требует пилотного цикла).

### 7. ИИ-аналитик для постановки ТЗ на ЗНИ

- **Что даёт:** улучшение качества заявок от бизнеса в ДИТ (60% «тормозов» уйдут).
- **Данные:** структурированные опросы, чек-листы (внутренний контур).
- **Готовность:** 🟢 после ввода сервера. **Согласовано с ДИТ на финальной встрече**.
- **Срок:** 4–6 недель.

### 8. Дизайнеры (внешние ИИ-сервисы)

- **Что даёт:** генерация изображений, текстов, упаковки, карточек маркетплейсов.
- **Данные:** общедоступные / маркетинговые, не КТ.
- **Готовность:** 🟢 после согласования способа оплаты заграничных сервисов (Gemini Nanobanana, Sora2, Midjourney) — **технический вопрос, не ИБ-вопрос**.
- **Срок:** 1–2 недели.

## Горизонт 2.1. Процессинг (данные есть, требуют нормализации)

### 9. Управление запасами / Прогноз спроса

- **Что даёт:** удержание оборачиваемости 21 день при росте портфеля.
- **Данные:** история отгрузок 1С + Excel + [платформа дистрибьюторов — NDA]. **Грязные данные дистрибьюторов**.
- **Готовность:** 🟡 — параллельно внедряется **[Вендор Б] (система прогнозирования спроса)** (2 года). На финальной встрече принято решение **не лезть до результатов**.
- **Срок:** после результатов [Вендора Б] (3–6 мес.).

### 10. Юридический помощник (ДПО)

- **Что даёт:** сравнение версий договоров, выявление расхождений, протоколы разногласий, контроль исполнения.
- **Данные:** ELMA (~15 000 договоров/год, 25% протоколов разногласий) + PDF-сканы + 30–40 шаблонов.
- **Готовность:** 🟡 — нужна доработка маршрутов в ELMA (сохранение истории комментариев).
- **Срок:** 4–6 месяцев. Тестирование Casebook/Caselook + платный Claude/ChatGPT для юриста — **уже сейчас**.

### 11. Речевая аналитика звонков продавцов / визитов на точки

- **Что даёт:** анализ соблюдения скриптов, отработки возражений, мест нарушения коммуникации.
- **Данные:** записи звонков + [мобильное приложение торговых представителей]. **КТ — цены, объёмы, акции**.
- **Готовность:** 🟡 — **только во внутреннем контуре**. Согласовано на финальной встрече после уточнения юридической стороны записи.
- **Срок:** 3–6 месяцев после ввода сервера.

### 12. Помощник менеджера (CRM Битрикс24, онбординг)

- **Что даёт:** консолидированная карточка клиента, ускорение подготовки КП, помощь в освоении CRM.
- **Данные:** 1С + Битрикс24. Не используется в продажах (зафиксировано).
- **Готовность:** 🟡 — нужно решение по лидерству внедрения CRM в продажах (см. раздел 05).
- **Срок:** 6–9 месяцев.

### 13. 1-я линия поддержки / автоклассификация почты

- **Что даёт:** маршрутизация входящих писем, автоответы по шаблонам.
- **Данные:** история обращений + ELMA + почта.
- **Готовность:** 🟡.
- **Срок:** 2–3 месяца.

### 14. Мониторинг отзывов и упоминаний бренда

- **Что даёт:** реакция на негатив с недель до часов; системные проблемы продукта/упаковки.
- **Данные:** **медиамониторинг [объём — NDA] упоминаний/мес** + [Вендор А] + 3 бота агентств. **Вендор-лок!**
- **Готовность:** 🟡 — нужна выгрузка в инхаус.
- **Срок:** 1–2 месяца.

### 15. Конкурентный анализ (после закрытия API WB)

- **Что даёт:** ценовое позиционирование на маркетплейсах.
- **Данные:** покупка через сервисы маркетплейсов (Ozon продаёт; WB готовит).
- **Готовность:** 🟡 — нужна интеграционная прокладка для аналитики покупаемых данных.
- **Срок:** 2–3 месяца.

### 16. Автоотчёты для управленческой отчётности

- **Что даёт:** экономия времени на подготовку отчётов 50–80%.
- **Данные:** BI/Power BI + Excel.
- **Готовность:** 🟡.
- **Срок:** 1–2 месяца.

### 17. ИИ-помощник программиста (ОРБП + ДИТ)

- **Что даёт:** ускорение разработки, поиск по кодовой базе, автогенерация документации.
- **Данные:** GitLab (локальный). КТ — платёжные реквизиты, бизнес-логика.
- **Готовность:** 🟡 — **только локально**. Стек: CodeLlama/StarCoder + Qdrant. Cursor + DeepSeek/Opus тестируется ДИТ.
- **Срок:** 3–4 месяца после ввода сервера.

## Горизонт 2.2. Фундамент (данных нет / гипотезы)

### 18. Предиктивная аналитика отказов оборудования (IIoT)

- **Что даёт:** переход от реактивного ремонта к плановому.
- **Данные:** 🔴 ⓘ **Гипотеза:** телеметрия только на единичных линиях (ток / температура / вибрация — большая часть НЕ снимается). Фасовочная линия — 10 датчиков.
- **Готовность:** 🔴 — **требуется аудит АСУТП с владельцем процесса**. Без перечня линий и глубины истории ML-пилот невозможен.
- **Срок:** оценка после доделки аудита.

### 19. R&D: ML по рецептурам и протоколам испытаний

- **Что даёт:** снижение COGS 3–7%, сокращение Time-to-Market в 2–3 раза.
- **Данные:** 🔴 ⓘ **Гипотеза:** LIMS (иностранный вендор on-premise) + Excel-архивы 5–10 лет. **Формат не верифицирован.**
- **Готовность:** 🔴 — **требуется аудит лаборатории** + подтверждение наличия связки «состав → свойства».
- **Срок:** оценка после доделки аудита. Сценарии: 6–9 мес. (LIMS зрелый) до 12+ мес. (бумажные журналы).

### 20. Компьютерное зрение (CV) для линий фасовки и упаковки

- **Что даёт:** контроль перекоса этикетки, уровня заполнения, обязательной маркировки. Снижение рекламаций 30–50%.
- **Данные:** 🔴 нужно собрать датасет 1000+ изображений нормы/брака.
- **Готовность:** 🔴 — заводская команда уже начала разметку. Нужен пилот на одной линии.
- **Срок:** 4–6 месяцев.

### 21. Цифровой двойник основного технологического оборудования

- **Что даёт:** оптимизация энергоёмких технологических процессов, подбор режимов под рецептуры.
- **Данные:** 🔴 SCADA / контроллеры (температура, давление, обороты) + протоколы качества готового продукта.
- **Готовность:** 🔴 — данных нет.
- **Срок:** оценка после аудита R&D и АСУТП.

### 22. Голосовые ИИ-роботы для колл-центра

- **Что даёт:** первичная консультация по подбору продукта, разгрузка операторов.
- **Данные:** 🔴 ⓘ — **встреча с руководителем КЦ не проведена**.
- **Готовность:** 🔴.
- **Срок:** оценка после доделки.

## Главный вывод по паспорту

> **Существенная часть направлений готова к пилоту прямо сейчас.** Это солидный фундамент — гораздо больше, чем «фрагмент давайте попробуем ML на складе». Запуск пилотов даст компании:
> 1. Измеримые быстрые победы;
> 2. Готовые требования к инфраструктуре (под Базовую конфигурацию LLM);
> 3. Аргументированную смету для CAPEX-инвестиций;
> 4. Сформированную команду и культуру для следующих горизонтов.
>
> Тормоз — **не отсутствие идей**, а **отсутствие функции, которая их реализует**.
>
> Деление проектов на классы по типу решения (внешние API / локальный сервер / автоматизация без ИИ) приведено в разделе 07.
