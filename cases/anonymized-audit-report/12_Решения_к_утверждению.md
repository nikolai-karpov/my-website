# 12. Решения к утверждению

> **Этот раздел — формальный «выход» аудита для протокола генерального директора.**
> Каждое решение сформулировано так, чтобы быть утверждённым приказом / резолюцией без дополнительных уточнений.

## РЕШЕНИЕ №1. Организационное

### Утвердить штатную единицу «Руководитель направления по внедрению искусственного интеллекта»

| Параметр | Значение |
|--------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|
| **Наименование должности** | Руководитель направления по внедрению искусственного интеллекта |
| **Функциональная роль** | Системный интегратор / архитектор ИИ-решений; «лидер изменений» |
| **Подчинение** | Заместителю генерального директора (или непосредственно ГД) |
| **Статус** | Отдельная штатная единица (не совмещение, не «дополнительная нагрузка») |
| **Дата ввода** | Немедленно (с даты утверждения) |
| **Команда (на этапе Г1)** | 3 разработчика: frontend / backend Java/TypeScript / Python (через HR — стандартный найм) |
| **Первоочередные задачи** | (1) Доделка аудита за 4 недели; (2) Запуск пилотов класса 3.1.1 (внешние API); (3) Подготовка инфраструктуры под класс 3.1.2; (4) Формирование инвестиционного меморандума |

### Полномочия, необходимые для функции

| Полномочие | Обоснование |
|-----------------------------------------------------------|---------------------------------------------------------------------------------------------------------------|
| **Прямой доступ к данным** | Без выгрузок из 1С, SCADA, LIMS, Excel-архивов, CRM, BI-отчётов в машиночитаемом виде доделка аудита и пилоты невозможны |
| **Прямые контакты в подразделениях** | 11 интервью за 4 недели (доделка) + регулярная синхронизация с Product Owners пилотов |
| **Участие в совещаниях по направлениям пилотов** | Координация ДИТ + ИБ + бизнес-заказчиков |
| **Право инициировать пилоты класса 3.1.1** | В рамках утверждённого бюджета (см. Решение №2) |
| **Право заключать подписки на внешние ИИ-сервисы** | В рамках утверждённого бюджета на подписки |
| **Право привлекать подрядчиков** (ТЗ, NDA, приёмка) | Для специализированных задач (CV, IIoT, RPA) — в рамках бюджета |

### KPI на этапе Г1 (0–3 месяца)

| Метрика | Целевое значение | Срок |
|---------------------------------------------------------------------------------------------------------------------|------------------------|-----------------------------|
| Закрыто белых пятен (из 11) | ≥ 9 | 4 недели |
| Утверждён классификатор данных (КТ / ПДн / публичные) | ✅ | 6 недель |

| Сервер введён в эксплуатацию | ✅ | конец месяца 1 |
| Запущено пилотов класса 3.1.2 (локальный сервер) | ≥ 2 | 8 недель |
| Сформирован инвестиционный портфель на следующий год | ✅ | 12 недель |

## РЕШЕНИЕ №2. Административное (мандат на доделку аудита)

| Параметр | Значение |
|------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| **Срок** | 4 рабочие недели с даты утверждения |
| **Статус** | 100% выделенного ресурса руководителя направления |
| **Объекты аудита** | См. перечень в разделе 10 |

### Перечень объектов

| № | Что закрывается |
|-------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 🔴 №1 | Руководитель R&D + лаборатория + LIMS-инвентаризация |
| 🔴 №2 | Главный инженер по АСУТП + перечень оснащённых линий |
| 🔴 №3 | Руководитель ИБ (формальное интервью) |
| 🔴 №4 | Сводная встреча с собственниками |
| 🟡 №5 | Главный бухгалтер |
| 🟡 №6 | Руководитель ДЦ (динамическое ценообразование) |
| 🟡 №7 | Владелец процессов BI |
| 🟡 №8 | Руководитель колл-центра |
| 🟡 №9 | Транспортная логистика + рекламации |
| 🟡 №10 | Контрактное производство (Private Label) |
| 🟢 №11 | R&D-директор; [продуктовые направления — NDA]; моделирование рецептуры; входной контроль |

### Предоставляемые полномочия

| Право | Содержание |
|---------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| **На доступ к данным** | Выгрузки из 1С, SCADA, LIMS, Excel-архивов, CRM, BI-отчётов |
| **На доступ к экспертам** | Проведение интервью с руководителями и ключевыми специалистами (до 3 ч на подразделение) |
| **На хронометраж** | Замер текущих трудозатрат на ключевые ручные процессы |
| **На инвентаризацию** | Проверка фактического состояния архивов R&D, телеметрии оборудования, истории сделок |

### Мандат НЕ даёт право

- ❌ Изменять текущие процессы подразделений;
- ❌ Останавливать или приостанавливать производственную / коммерческую деятельность;
- ❌ Принимать решения о выделении бюджетов на пилоты или закупку оборудования сверх рамок Решения №1.

### Ожидаемый результат доделки

**Утверждённые артефакты:**

| Артефакт | Назначение |
|-------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------|
| Паспорт данных без пометки «гипотеза» | Замена цветовых статусов 🔴ⓘ на верифицированные 🔴 / 🟡 / 🟢 |
| **Утверждённый классификатор данных** (КТ / ПДн / публичные) | Снимает все блокировки ИБ для пилотов класса 3.1.2 |
| **Точная смета на оцифровку R&D-архивов** | Замена вилки 2–5 млн ₽ |
| **Точная смета на IIoT-дооснащение** | Замена вилки 6–22 млн ₽ |
| **Решения по 4 запертым пилотам** (Бухгалтерия, ДЦ, КЦ, BI) | Включение в шорт-лист или формальное закрытие |
| **Стратегическое согласование собственников** | Возможность защиты CAPEX-бюджета на портфель «Фундамент» |

### Бюджет на это решение

ФОТ руководителя направления (уже выделен в рамках Решения №1).

## РЕШЕНИЕ №3. Инфраструктурное

### Поручить ДИТ совместно с ИБ и руководителем направления по ИИ:

#### Задача 1. Завершить ввод сервера в эксплуатацию до конца месяца 1

| Шаг | Срок | Ответственный |
|---------------------------------------------------------------------------------|-----------------------------------------|-----------------------------------------------|
| Сервер выходит с таможни | ~2 недели | ДИТ |
| Монтаж, пусконаладка | ~10 дней | ДИТ |
| Развёртывание базового LLM-стека | до конца месяца 1 | ДИТ + Руководитель ИИ |

**Запасной вариант (страховка):** при риске задержки — рассмотреть аренду / лизинг GPU-станций у российского облачного провайдера в защищённом контуре (0,8–1,2 млн ₽; 2–3 недели; находится в периметре компании).

#### Задача 2. Утвердить классификатор данных (КТ / ПДн / публичные) до середины месяца 2

**Что входит:**

- Перечень категорий данных в каждом подразделении;
- Уровень чувствительности и допустимые методы обработки;
- Регламент работы с анонимизатором для пилотов класса 3.1.1;
- Поправки к СТО по использованию ИИ.

**Ответственные:** руководитель ИБ (после формального интервью в рамках доделки аудита) + ДИТ + руководитель ИИ.

#### Задача 3. Утвердить архитектуру корпоративного LLM-контура до конца месяца 2

**Что входит:**

- Сценарии использования (10–15 задач) с приоритетами;
- Расчёт необходимой GPU-мощности под пилотные сценарии;
- Выбор модели (open-source: LLaMA 3 / Mistral / Qwen);
- Векторная БД и фреймворк для RAG;
- Проектирование интеграционного слоя с 1С / ELMA / Битрикс24;
- Требования к разграничению прав;
- Интеграция с AD и системами логирования.

**Ответственные:** ДИТ + руководитель ИИ.

### Что это решение **НЕ означает**

- ❌ Не решение о закупке нового сервера (текущий — на таможне);
- ❌ Не решение о выборе вендора ИИ-платформы;
- ❌ Не решение о старте промышленной эксплуатации.

### Что это решение **означает**

- ✅ Решение о синхронизации сроков ДИТ + ИБ + руководителя ИИ;
- ✅ Решение о готовности к пилотам класса 3.1.2 после ввода сервера и классификатора;
- ✅ Решение о готовности компании к стратегической инвестиции в Базовую конфигурацию LLM (CAPEX 2,5–3,5 млн ₽) **после** успешных пилотов на MVP-инфраструктуре.

### Бюджет на это решение

В рамках текущего ФОТ ДИТ + ИБ. Закупки оборудования — отдельным решением **по итогам пилотов**.

## Что произойдёт при отклонении решений

| Если | То |
|----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|
| **Не утвердить Решение №1** | Все 27 интервью аудита остаются в формате «справки руководителю». Реализация любого пилота требует владельца ответственности. Без него — деньги уйдут в стол. |
| **Не утвердить Решение №2** | Сметы по портфелю «Фундамент» (R&D + IIoT + CV) останутся гипотетическими. CAPEX-бюджет на 13–38 млн ₽ защитить нельзя. R&D и предиктивная аналитика отказов — за горизонтом обозримого. |
| **Не утвердить Решение №3** | Сервер останется «оборудованием в кладовой». Все пилоты класса 3.1.2 (14 проектов) заморожены. ИИ остаётся в формате «персональных экспериментов» сотрудников на телефонах. |
