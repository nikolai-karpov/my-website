# Обезличенный отчёт аудита готовности к ИИ

Источник артефакта для скачивания на сайте: `downloads/anonymized-ai-audit-report.pdf`
(ссылки — на главной в карточке кейса и на `site-pages/holding-audit.html`).

Обезличенная версия реального аудиторского отчёта (NDA-плейсхолдеры согласованы
с заказчиком). Источник истины — md-разделы `00_…13_…`; единый
`Обезличенный_отчет_аудита_ИИ.md`, DOCX и PDF собираются из них.

## Пересборка после правок разделов

```bash
cd cases/anonymized-audit-report
for f in 00_О_документе.md 01_*.md 02_*.md 03_*.md 04_*.md 05_*.md 06_*.md \
         07_*.md 08_*.md 09_*.md 10_*.md 11_*.md 12_*.md 13_*.md; do
  cat "$f"; printf '\n\n---\n\n'
done > "Обезличенный_отчет_аудита_ИИ.md"
LANG=en_US.UTF-8 pandoc _meta.yaml "Обезличенный_отчет_аудита_ИИ.md" \
  -o "Обезличенный_отчет_аудита_ИИ.docx" --toc --toc-depth=2
soffice --headless --convert-to pdf "Обезличенный_отчет_аудита_ИИ.docx" --outdir .
cp "Обезличенный_отчет_аудита_ИИ.pdf" ../../downloads/anonymized-ai-audit-report.pdf
```

Метаданные (заголовок/автор) передаются только через `_meta.yaml` — не через
`--metadata` в командной строке (иначе кириллица в титуле бьётся из-за локали).

## Проверка обезличивания

Перед публикацией правок — grep по стоп-словарю (название заказчика во всех
вариантах, продуктовые категории, нишевые вендоры, конкуренты, точные суммы
и даты) должен давать ноль совпадений.
