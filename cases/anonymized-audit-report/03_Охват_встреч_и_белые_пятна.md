### ⚠️ Покрыто частично — данных недостаточно

| Направление | Что есть | Чего не хватает |
|-------------------------------|--------------------------------------------------------------------|-----------------------------------------------------------------------|
| **R&D (рецептуры, протоколы испытаний)** | Письменное подтверждение интереса, отказ от внешних API без локального сервера | Не проведено интервью с руководителем R&D, не верифицирован формат хранения LIMS, не оценён объём архивов |
| **Производственная телеметрия (АСУТП)** | Зам. директора ИТ озвучил «телеметрия только на единичных линиях, на фасовочной — 10 датчиков» | Не проведено интервью с владельцем АСУТП, не получен перечень оснащённых линий, не оценена глубина истории |
| **Транспортная логистика и рекламации** | Через складскую логистику получены косвенные данные (1500 ₽/час простоя, 5000 ₽/сутки регионы) | Не проведено отдельное интервью с руководителем транспортной логистики и отделом рекламаций |
| **СУУ / финансовая аналитика** | Письменный материал получен | Не проведено живое интервью с руководителем СУУ |

### ❌ Не покрыто (белые пятна)

| № | Кто | Почему критично | Последствие отсутствия данных |
|-------------|------------------------------------------------|-------------------------------------------------------|-------------------------------------------------------|
| 🔴 №1 | **Руководитель R&D** | Архивы рецептур и протоколов испытаний 5–10 лет — стратегический актив для оптимизации COGS и Time-to-Market | Без аудита формата (LIMS / Excel / бумага) **невозможна оценка стоимости оцифровки**. Любые ML-сметы по R&D — гадание |
| 🔴 №2 | **Главный инженер по АСУТП / производственной телеметрии** | Предиктивная аналитика отказов = ключевой класс ML-проектов для производства | Без понимания, что снимают датчики (ток / вибрация / температура) и за какой период есть история — нельзя оценить готовность к Predictive Maintenance |
| 🔴 №3 | **Руководитель ИБ (прямой диалог)** | На финальной встрече присутствовал представитель ИБ, но **формального интервью** с руководителем ИБ как стейкхолдером не было. Все запросы шли через ДИТ | Нет утверждённого классификатора данных (КТ / персональные / публичные). Без него любой пилот — лотерея |
| 🔴 №4 | **Собственники** | Стратегическое видение и согласие на технологическую перестройку | Решения по бюджету ИИ требуют согласия собственников; косвенно получено от ГД, но прямого диалога не было |
| 🟡 №5 | **Главный бухгалтер** | Пилот «Бухгалтерия» приоритезирован операционным директором | Невозможно оценить специфику пилота (OCR + LLM для проводок) |
| 🟡 №6 | **Руководитель ДЦ (динамическое ценообразование)** | Самое перспективное направление по эффекту (5–10% маржи) | Не известны процессы ДЦ, формат данных, состав команды |
| 🟡 №7 | **Владелец процессов BI** | BI — основная точка интеграции для аналитики | Не зафиксированы текущие BI-практики, готовность к интеграции с LLM |
| 🟡 №8 | **Руководитель колл-центра** | Эскалация после встречи с блогерами/соцсетями (там подняли вопрос о голосовых ИИ-роботах) | Не оценена нагрузка КЦ, не получены данные для пилота голосовых роботов |
| 🟡 №9 | **Контрактное производство (Private Label)** | Отдельная бизнес-линия, специфика не раскрыта | Невозможно оценить применимость ИИ для CP |
| 🟢 №10 | **R&D-директор (отдельно от лаборатории)** | Упомянут как «харизматичный», есть идея «цифрового двойника эксперта» для обучения | Идея не проработана |
| 🟢 №11 | **Отдельные процессы R&D**: [продуктовые направления — NDA], моделирование рецептуры, входной контроль | Каждый — отдельный класс задач для ИИ | Не оценены |

### ➕ Расширения скопа в ходе аудита

В процессе всплыли направления, которых не было в первоначальном плане. Они закрыты — это **расширение покрытия**, а не пробел:

- **Юридический департамент (ДПО)** — ~15 000 договоров/год, 25% протоколов разногласий. Сильный кандидат на пилот «помощник юриста».
- **ОДО (отдел документационного обеспечения)** — обсуждался на финальной встрече ДИТ+ИБ.
- **ОРБП** — программисты, потребность в локальном AI-помощнике (CodeBERT, CodeLlama).
- **E-commerce** — расхождения 1С↔маркетплейсы (потери [сумма — NDA]), API WB закрыт.
- **Технический маркетинг** — [Вендор А] покрывает 86% автоответов, Telegram-бот подбора продукта [объём — NDA] запросов/мес.

## 3.3. План доделки белых пятен

При утверждении продолжения функции — закрыть критические пробелы за 4 рабочие недели:

| Неделя | Встречи (приоритет 🔴) |
|--------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Руководитель R&D + лаборатория (LIMS / архивы) |
| 1 | Главный инженер по АСУТП (телеметрия, перечень линий) |
| 2 | Руководитель ИБ (формальное интервью + классификатор данных) |
| 2 | Главный бухгалтер (пилот «Бухгалтерия») |
| 3 | Руководитель ДЦ (динамическое ценообразование) |
| 3 | Владелец процессов BI |
| 4 | Колл-центр, Private Label, отдельные процессы R&D |
| 4 | Сводная встреча с собственниками (по результатам) |

**Бюджет на доделку:** ФОТ руководителя направления (уже выделен).

**Без этого этапа** оценка стоимости оцифровки R&D-архивов и дооснащения производства датчиками **остаётся гипотетической** (вилки в десятки млн ₽), а сметы для инвестиционного меморандума **не могут быть подготовлены**.
