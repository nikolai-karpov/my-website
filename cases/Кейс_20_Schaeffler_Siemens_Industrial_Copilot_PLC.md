# Кейс 20: Schaeffler + Siemens — Industrial Copilot на производственной машине (GenAI для PLC)

**Производственный сценарий:** GenAI для инженерии автоматизации, сокращение простоев (заявлено)
**Отрасль:** Машиностроение / оборудование для производства
**Страна / регион:** Германия (премьера SPS Nuremberg 2023)
**Охват внедрения:** пилот / демонстрация на машине; далее пилот на robot cell (Schaeffler press)
**Уровень доказательности:** средний (подтверждение факта партнёрства и функций; **без численных KPI** в пресс-релизе)
**Балльная шкала (9/12):** 3 + 2 + 1 + 3
**Дата обращения к источникам:** 2026-05-01

---

## Производственный контекст

Нехватка инженеров автоматизации; необходимость ускорить цикл «изменение кода PLC → запуск».

## Задача

Генерация кода **PLC** по естественному языку; ускорение поиска решений по документации; снижение ошибок и времени на диагностику.

## AI/ML-подход

**Siemens Industrial Copilot** + **TIA Portal Openness** API; доступ к мануалам и гайдам.

## Данные

Документация Siemens, код автоматизации, контекст ошибок (по описанию).

## Результат и метрики

Пресс-релиз Siemens: «**significantly reduce time, effort, and the probability of errors**» при генерации PLC-кода; «**help to significantly reduce machine downtime**» — **без чисел**.
