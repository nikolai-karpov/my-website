# Кейс 3: NotCo — ИИ-платформа Giuseppe

**NotCo** использует ИИ-платформу **Giuseppe**, чтобы заменять животные молекулы растительными, сохраняя вкус и текстуру. Этот опыт напрямую применим к машинным маслам, где критичны **функциональные свойства** (вязкость, термостабильность), а не органолептика.

---

## 1. Технический процесс и методы ИИ

### 1.1. Методы

Используются алгоритмы машинного обучения для анализа молекулярного состава продуктов. Ключевой метод — **молекулярный подбор (molecular matching):** ИИ сопоставляет структуру целевого продукта (например, молока) с базой данных растений, чтобы найти комбинации, дающие ту же вязкость и стабильность.

### 1.2. Архитектура и обучение

- **Слой распознавания (Discernment Layer):** ИИ обучается на обратной связи от людей (эксперты по сенсорике, шеф-повара), которые оценивают прототипы.
- **Оптимизация:** Алгоритмы минимизируют «расстояние» между химическими профилями оригинала и копии.

### 1.3. Разметка данных

Сочетание **объективных химических данных** (ГХ-МС, жидкостная хроматография) и **субъективных оценок** (вкус, запах, текстура), переведённых в цифровой вид.

---

## 2. Датасеты и команда

- **Данные:** Проприетарная база данных из тысяч растений: молекулярные профили, физико-химические свойства и функциональные характеристики.
- **Команда:** Смешанная — AI-инженеры, учёные-пищевики (food scientists), химики и технологи. Общая численность компании — несколько сотен человек (включая производство и маркетинг).
- **Бюджет:** Привлечено более **$460 млн** (оценка компании до **$1.5 млрд**). Среди инвесторов — Джефф Безос (Bezos Expeditions).

---

## 3. Перенос опыта на масла и антифризы

Для разработки ГСМ логика Giuseppe адаптируется так:

- **Замена вкуса на трибологию:** Вместо «вкуса/запаха» целевыми параметрами становятся индекс вязкости, температура вспышки, противоизносные свойства (пятно износа) и антикоррозийная защита.
- **Молекулярный дизайн:** Создание «цифровых двойников» присадок и базовых масел. ИИ ищет синергию компонентов, которую сложно просчитать вручную.
- **Ускорение R&D:** NotCo сокращает цикл разработки с лет до месяцев. В маслах это позволит быстро подбирать пакеты присадок под новые экологические стандарты или заменять дефицитные компоненты без потери свойств.

---

## 4. Архитектура поиска рецептур для масел и антифризов (аналог Giuseppe)

Стек технологий на стыке **хеминформатики (Cheminformatics)** и **Deep Learning**.

### 4.1. Ядро системы: хеминформатика

Задача — перевод химических формул в цифровой вид для ИИ.

- **RDKit:** Главная библиотека для работы с молекулами. Генерация дескрипторов (физико-химические свойства) и «отпечатков» (fingerprints) молекул присадок и базовых масел.
- **DeepChem:** Фреймворк для глубокого обучения в химии. Предобученные модели для предсказания растворимости, вязкости и токсичности.
- **SMILES:** Текстовое представление структуры молекул для подачи в нейросети.

### 4.2. Модели и алгоритмы (ML/DL)

Для ГСМ критичны нелинейные зависимости между компонентами.

- **Chemprop:** Библиотека на базе **Graph Convolutional Neural Networks (GCNN)**. Анализ молекул как графов — подходит для предсказания свойств новых присадок.
- **Gaussian Processes (GP) и Bayesian Optimization:** Оптимизация составов (blending). ИИ предлагает рецептуру → результат теста → обновление модели; минимизация числа реальных лабораторных варок.
- **XGBoost / Random Forest:** Регрессия на табличных данных (например, предсказание индекса вязкости по процентному соотношению компонентов).

### 4.3. Инженерный стек (Infrastructure)

- **Python** — базовый язык.
- **PyTorch / TensorFlow** — кастомные нейросетевые архитектуры.
- **Pandas & NumPy** — обработка массивов данных испытаний (трибология, окисление).
- **MLflow / DVC** — версионирование моделей и данных (каждый лабораторный эксперимент дорог).

### 4.4. Данные (Dataset & Input)

В отличие от NotCo (растения), датасет для масел и антифризов включает:

- **Спектроскопия (FTIR):** ИК-спектроскопия для идентификации и предсказания концентрации присадок (ZnDDP, MoDTC).
- **Трибологические логи:** Данные с четырёхшариковых машин трения (диаметр пятна износа, нагрузка сваривания).
- **PubChem / ChEMBL:** Базовые характеристики молекул-кандидатов.

**Рекомендация:** начать с прототипа на **DeepChem** и **RDKit**, используя исторические данные о замесах масел как обучающую выборку.

## 5. Дорожная карта MVP «Giuseppe для ГСМ» (4–6 месяцев)

Фокус — не на масштабной базе, а на **предиктивной способности** подбирать компоненты под заданный допуск (например, API SP или ACEA C3).

| Этап                                              | Срок       | Задачи                                                                                                                                                                                                                                           |
| ------------------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1. Оцифровка и структурирование данных**        | 1 месяц    | Перевод протоколов (LIMS) из PDF/Excel в единую базу (SQL/NoSQL). Features: вход — % базовых масел (Группы I–V) и пакетов присадок (CAS); выход — вязкость (−35°C…100°C), NOACK, CCS, пятно износа, TBN. Нормализация данных разных лабораторий. |
| **2. Предиктивная модель**                        | 1,5 месяца | «Виртуальная лаборатория»: Gradient Boosting (XGBoost/LightGBM) для табличных рецептур; физико-химические ограничения (например, уравнение Вальтера) в функции потерь; обучение на 10–15 базовых компонентах.                                    |
| **3. Модуль генерации рецептур**                  | 1 месяц    | Инверсия: «Хочу 5W-30 с вязкостью X и ценой Y — дай состав». Байесовская оптимизация; cost-optimization (веса стоимости компонентов); RDKit для проверки совместимости и исключения конфликтующих присадок.                                      |
| **4. Верификация и дообучение (Active Learning)** | 1 месяц    | Лабораторный тест 3–5 вариантов от ИИ; feedback loop (результаты в систему, корректировка весов); UI (Dash/Streamlit): слайдеры параметров → список компонентов.                                                                                 |

---

## 6. Ресурсный план для MVP

- **Команда:** 1 Data Scientist (ML/химия), 1 инженер данных, 1 главный технолог (эксперт-валидатор).
- **Инструментарий:** Python (RDKit, Chemprop); облачные вычисления (на этапе MVP достаточно CPU, GPU не обязательны).
- **Бюджет на R&D:** Основные затраты — оплата команды и проведение контрольных лабораторных тестов.

---

## Релевантность для проекта Группа Синтез

Кейс демонстрирует:

- **Молекулярный подбор (molecular matching)** как парадигму замены компонентов при сохранении целевых свойств — в маслах это замена дефицитных присадок и подбор под новые стандарты.
- Готовый технологический стек для «Giuseppe под ГСМ»: RDKit, DeepChem, Chemprop, GP + Bayesian Optimization, XGBoost/RF.
- Конкретный сценарий **MVP за 4–6 месяцев** с этапами оцифровки, предиктивной модели, генерации рецептур и Active Learning.
- Минимальный состав команды (3 человека) и акцент на стоимости контрольных тестов, а не на инфраструктуре.
