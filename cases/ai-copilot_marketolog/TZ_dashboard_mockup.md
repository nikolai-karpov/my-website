## 1. Цель макета

Показать продукт «Дашборд маркетолога с AI-CoPilot» как кейс в портфолио: не абстрактный лендинг про аналитику, а **рабочий cockpit**, в который маркетолог заходит каждое утро и за 5 секунд понимает — бизнес растёт или теряет деньги, и куда смотреть прямо сейчас.

## 4. Что НУЖНО ДОРАБОТАТЬ (с приоритетами)

### P0 — Критично для портфолио-кейса

#### 4.1. Sparklines в KPI-карточках
**Проблема:** Карточки показывают число + delta, но нет мини-графика за 7–30 дней.
**Решение:** Добавить sparkline (20–30 px высотой) в каждую из 8 KPI-карточек. Sparkline показывает тренд за выбранный период. Даже mock-данные — просто линия из 7 точек.

```
┌─────────────────┐
│ GOAL CPA        │
│ ⚠ Warning       │
│ 916 ₽  +22%     │
│ ▁▂▃▅▆█ ←spark   │
└─────────────────┘
```

#### 4.2. Пороги вмешательства рядом с метриками
**Проблема:** «CTR 1.1%» говорит «ниже порога», но порог не показан.
**Решение:** Добавить строку с порогом под значением:

```
CTR 7D
⚠ Warning
2.01%  −0.3%
порог: 2.5%
```

Цвет: если значение пересекло порог — красная/жёлтая/зелёная полоса слева от карточки.

#### 4.3. Воронка конверсий
**Проблема:** Нет виджета «Показы → Клики → Визиты → Вовлечённые → Цель».
**Решение:** Добавить горизонтальную воронку под KPI-карточками, над таблицей проектов. Каждый шаг показывает абсолютное число и % перехода. Подсветка шага с аномальным drop-off (>20% vs среднее).

Mock-данные для портфолио из 5 проектов:
```
Показы 17 182 → Клики 882 (5.1%) → Визиты 825 (93.5%) → Цели 33 (4.0%)
                                              ↑ OK                  ↑ DROP
```

#### 4.4. Budget Pacing
**Проблема:** Нет ответа на вопрос «хватит ли бюджета до конца месяца?»
**Решение:** Добавить виджет рядом с воронкой (или вместо очереди действий, если не хватает места):

```
BUDGET PACING
━━━━━━━━━━━━━━░░░░░░  68%
Расход: 30 230 ₽ / План: ~45 000 ₽
День: 10/30 → Прогноз: хватит до 26-го
```

Progress bar + прогнозная дата исчерпания.

#### 4.5. Визуальная иерархия алертов
**Проблема:** Critical и Warning карточки одного размера и одного визуального веса.
**Решение:**
- Critical: красная полоса 4px слева, фон чуть розоватый,字号 на 20% крупнее
- Warning: жёлтая полоса 2px слева, обычный размер
- Критические алерты — первые, неразвёрнутые по умолчанию (Collapsed: Signal + 1 строка)
- Warning — раскрыты, показывают детали

#### 4.6. «Восходящая звезда» — позитивные сигналы
**Проблема:** Только негативные сигналы (CPA не определён, CTR ниже, Tracking broken). Нет позитивных.
**Решение:** Добавить 1–2 карточки с позитивными сигналами:

```
🟢 Анонимайзер: CPA 692 ₽
Целевой CPA: 900 ₽. Фактический на 23% ниже.
Confidence: 92%
Рекомендация: Рассмотреть увеличение бюджета на 20%
Риск: Рост бюджета может повысить CPA
```

### P1 — Важно для полноты кейса

#### 4.7. Расширение карточек AI-инсайтов до 14 полей
**Проблема:** Сейчас 6 из 14 полей. Нет: Baseline, Delta (%), Trend, Last updated, Likely cause, Review period, Rollback condition.
**Решение:** Раскрывать дополнительные поля по клику на карточку (accordion). В свёрнутом виде: Signal + Confidence + 1 строка. В раскрытом — все 14 полей.

#### 4.8. Evidence drawer (функциональная кнопка)
**Проблема:** Кнопка «Evidence» есть, но не работает.
**Решение:** При клике раскрывается панель справа (slide-in):
- Источник: Яндекс Директ API / Яндекс Метрика / Wordstat
- Свежесть: Live / 15 мин / 1 ч / 3 ч
- Формула расчёта (для CPA: campaign cost / goal reaches)
- Ограничения: «Direct Conversions не считаются лидами»
- Ссылка на артефакт (mock)

#### 4.9. Детали проекта — drill-down
**Проблема:** Вкладка показывает те же KPI-карточки, что и первый экран. Нет углубления.
**Решение:** При переходе в «Детали проекта» (по клику на строку таблицы):
- История по дням (7-дневный график Spend/CTR/CPA)
- Разбивка по устройствам (Desktop/Mobile/Tablet)
- Разбивка по гео (топ-5 регионов)
- Поисковые запросы конкретной кампании
- Тексты объявлений с CTR
- UTM-связки

#### 4.10. Wordstat / Demand Fit
**Проблема:** Конкурентное преимущество (российский контур + Wordstat) не показано.
**Решение:** Добавить блок в Portfolio Cockpit (между воронкой и таблицей) или в «Детали проекта»:

```
СПРОС ПО КЛАСТЕРАМ (Wordstat)
███ ИИ-ассистент ████████ 1 240
███ Анонимизация ██ 380
███ Защита ПДн ████ 560
░░░ Инвестор ░ 90
```

Горизонтальные бары с частотностями из Wordstat.

## 6. Технические требования

- **Формат:** HTML + CSS + минимальный JS (для аккордеонов, sparklines, фильтров)

- **Данные:** Mock, реалистичные, из реальных кампаний
- **Адаптивность:** Desktop-first
- **Не ломать** существующие вкладки и данные
- **Sparklines:** SVG или canvas, 7–14 точек, минимальный размер
