# 📋 Быстрые команды для Cursor AI

Справочник команд для быстрой работы с AI агентом в Cursor.

## 🚀 Git операции и деплой

### Деплой изменений
```
Закоммить и запушить все изменения с сообщением "[ваше сообщение]"
```

**Примеры:**
- `Закоммить и запушить все изменения с сообщением "обновление стилей"`
- `Закоммить и запушить все изменения с сообщением "исправление багов"`

### Быстрый деплой (автоматическое сообщение)
```
Проиндексируй все изменения, создай коммит с автоматическим сообщением (дата и время) и отправь в репозиторий
```

### Сборка и деплой
```
Собери проект (npm run build), закоммить все изменения с сообщением "[сообщение]" и отправь в репозиторий
```

**Пример:**
- `Собери проект, закоммить все изменения с сообщением "новая функциональность" и отправь в репозиторий`

### Проверка статуса
```
Проверь статус git репозитория
```

### Синхронизация с удаленным репозиторием
```
Синхронизируй локальный репозиторий с удаленным (git fetch и git pull)
```

## 💡 Быстрые команды (короткие версии)

Для еще более быстрого доступа используйте короткие команды:

- `deploy "сообщение"` → Деплой с сообщением
- `quick` → Быстрый деплой с автосообщением
- `build-deploy "сообщение"` → Сборка + деплой
- `check styles` → Проверка стилей
- `analyze` → Анализ проекта
- `sync` → Синхронизация с репозиторием

## ⚙️ Настройка Custom Commands в Cursor

Для еще более быстрого доступа настройте Custom Commands:

1. Откройте настройки: `Cmd+,` (macOS) или `Ctrl+,` (Windows/Linux)
2. Найдите "Cursor Settings" → "Custom Commands"
3. Добавьте команды:

### Команда 1: Deploy
- **Название:** `Deploy`
- **Команда:** `Проиндексируй все изменения, создай коммит с сообщением "{input}" и отправь в репозиторий. Если сообщение не указано, используй: "Обновление: [текущая дата и время]".`
- **Горячая клавиша:** `Cmd+Shift+D`

### Команда 2: Build & Deploy
- **Название:** `Build & Deploy`
- **Команда:** `Собери проект (npm run build), проиндексируй все изменения, создай коммит с сообщением "{input}" и отправь в репозиторий.`
- **Горячая клавиша:** `Cmd+Shift+B`

### Команда 3: Quick Commit
- **Название:** `Quick Commit`
- **Команда:** `Закоммить все изменения с сообщением "{input}" и запушить в репозиторий.`
- **Горячая клавиша:** `Cmd+Shift+C`
