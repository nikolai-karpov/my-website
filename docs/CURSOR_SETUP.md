# ⚙️ Настройка Custom Commands в Cursor

Пошаговая инструкция по настройке быстрых команд в Cursor.

## 📋 Шаг 1: Открыть настройки

1. Нажмите `Cmd+,` (macOS) или `Ctrl+,` (Windows/Linux)
2. Или через меню: `Cursor` → `Settings` → `Settings`

## 📋 Шаг 2: Найти Custom Commands

1. В поиске настроек введите: `custom commands`
2. Или перейдите: `Cursor Settings` → `Custom Commands`

## 📋 Шаг 3: Добавить команды

Нажмите кнопку `+ Add Command` и добавьте следующие команды:

---

### 🚀 Команда 1: Deploy

**Название:**
```
Deploy
```

**Команда:**
```
Проиндексируй все изменения, создай коммит с сообщением "{input}" и отправь в репозиторий. Если сообщение не указано, используй автоматическое: "Обновление: [текущая дата и время]".
```

**Горячая клавиша (опционально):**
```
Cmd+Shift+D
```

**Описание:**
Быстрый деплой изменений в репозиторий.

---

### 🔨 Команда 2: Build & Deploy

**Название:**
```
Build & Deploy
```

**Команда:**
```
Собери проект (npm run build), проиндексируй все изменения, создай коммит с сообщением "{input}" и отправь в репозиторий.
```

**Горячая клавиша (опционально):**
```
Cmd+Shift+B
```

**Описание:**
Сборка проекта и деплой в репозиторий.

---

### ⚡ Команда 3: Quick Commit

**Название:**
```
Quick Commit
```

**Команда:**
```
Закоммить все изменения с сообщением "{input}" и запушить в репозиторий.
```

**Горячая клавиша (опционально):**
```
Cmd+Shift+C
```

**Описание:**
Быстрый коммит и пуш без сборки.

---

### 🔍 Команда 4: Check Styles

**Название:**
```
Check Styles
```

**Команда:**
```
Проверь все SCSS файлы на ошибки и исправь их автоматически.
```

**Горячая клавиша (опционально):**
```
Cmd+Shift+S
```

**Описание:**
Проверка и автоисправление стилей.

---

### 📊 Команда 5: Analyze Project

**Название:**
```
Analyze Project
```

**Команда:**
```
Проанализируй структуру проекта и найди потенциальные проблемы.
```

**Горячая клавиша (опционально):**
```
Cmd+Shift+A
```

**Описание:**
Анализ проекта на наличие проблем.

---

## 🎯 Как использовать

### Через Command Palette

1. Нажмите `Cmd+Shift+P` (macOS) или `Ctrl+Shift+P` (Windows/Linux)
2. Введите название команды (например, "Deploy")
3. Введите сообщение коммита (если требуется)
4. Нажмите Enter

### Через горячие клавиши

1. Нажмите назначенную горячую клавишу (например, `Cmd+Shift+D`)
2. Введите сообщение коммита (если требуется)
3. Нажмите Enter

### Через чат

1. Откройте чат Cursor AI
2. Введите команду из файла `CURSOR_COMMANDS.md`
3. Отправьте сообщение

---

## 💡 Советы

- Используйте `{input}` для запроса текста у пользователя
- Назначайте горячие клавиши для самых частых команд
- Группируйте похожие команды по категориям
- Регулярно обновляйте список команд по мере необходимости
