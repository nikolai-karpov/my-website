- **Предлагаемая подпись:** Как профессиональная роль, методика, инструменты и шаблон связаны с результатом.
- **Проверка перед включением:** Не изображать артефакт как ещё одну инструкцию. Отдельно показать источники. Не сводить схему к обязательной линейной цепочке из пяти вызовов.

### V02 — Вклад коллег и эволюция каталогов

- **Вставка:** После абзаца об отдельном каталоге принятого комплекта релиза.
- **Формат:** Новая схема; текущие снимки — вспомогательные, новый реальный кадр предпочтительнее.
- **Предлагаемая подпись:** Как совместная практика привела к отдельным рабочим пространствам документов и единому комплекту релиза.
- **Проверка перед включением:** Все рабочие MD/DOCX — черновики. Не добавлять отдельный draft/ по старому снимку. agent-05 содержит исторический вывод с draft в artifact_subdirs; он не подтверждает новый контракт.

### V03 — Оцифровка таблицы, продолжающейся на нескольких страницах

- **Вставка:** После абзаца «Для таблиц я закреплял требование сохранять их логическую целостность…».
- **Формат:** Новая пара исходник/результат на обезличенном проверенном примере.
- **Предлагаемая подпись:** Граница страницы не должна разрывать логическую таблицу.
- **Проверка перед включением:** Для фактического кейса нужны источник и сверенный результат одного прогона. До такого прогона допускается только явно подписанный учебный пример; не изображать его свидетельством работы парсера.

### V04 — Схема из документа → машиночитаемое представление

- **Вставка:** После абзаца «Для схем важно сохранить участников, действия, связи…».

- **Предлагаемая подпись:** При переносе схемы сохраняется смысл связей, а не только внешний вид.
- **Проверка перед включением:** Синтаксически правильный рендер не равен смысловой сверке. kilo-09/10 не использовать как результат оцифровки. Реальный или учебный статус примера указать прямо.

- **Проверка перед включением:** Один и тот же ID в обоих фрагментах; ссылка должна работать. Не превращать отсутствие ответа в выдуманное значение. Для учебного примера использовать нейтральный домен.
