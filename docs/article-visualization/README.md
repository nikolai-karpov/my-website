## Что установлено

В статье нет содержательных изображений. В каталоге навигатора 27 PNG — 21 уникальный кадр и шесть пар точных дублей. Навигатор использует 17 уникальных PNG в 18 включениях, а также содержит пять явных заглушек. Часть визуального материала уже сделана в HTML: маршруты задач, деревья раскладок и пятиэтапный путь артефакта. Отсутствие PNG не означает, что там нет схемы.

Существующий набор в основном показывает подключение рабочего места и GitLab. Для статьи наиболее полезны дерево канона, выбор роли, поручение Layout Builder и результат раскладки. Готовых кадров оцифровки таблиц/схем, вопросов в черновике, итогового DOCX и уровней памяти в этом наборе нет.

## Первая очередь — восемь иллюстраций

1. **V01** — связка роль/навык/инструмент/шаблон/артефакт.
2. **V02** — было/стало в каталогах, вклад коллег, рабочие версии и отдельный релиз.
3. **V03** — целостная таблица из двух страниц исходника.
4. **V04** — схема исходника и проверенное машиночитаемое представление.
5. **V05** — вопрос в реестре и ссылка на него в документе.
6. **V06** — шаблон и Markdown → DOCX → проверки → приёмка → релиз.
7. **V08** — реальный интерфейс навигатора с одним маршрутом задачи.
8. **V11** — действующие уровни памяти и отдельно планируемый владелец рефлексии.

Это рекомендуемый набор, не утверждённое количество. V03/V04 можно расположить рядом как два отдельных примера одной темы; на мобильном они должны идти последовательно. Остальные сюжеты P2 добавляются, если они дают новую информацию и не перегружают статью.

## Порядок работ после согласования

### 1. Утвердить смысл каждого кадра

Идти по одному ID реестра. Утверждать, что должен понять читатель, место вставки, тип материала (реальный снимок / схема / учебный пример), подпись и условия готовности. Реестр отличает существующий файл, существующую HTML-основу и полностью новый материал.

### 2. Собрать реальные доказательные примеры

Для V03, V04 и V06 нужны обезличенные исходник и результат, которые можно сверить между собой. Для V05 — один вопрос и действительно связанный с ним фрагмент черновика. Если фактического результата нет, использовать явно подписанный демонстрационный пример либо объясняющую схему. Скрин --help, smoke-отчёт и наличие файла не заменяют предметный результат.

### 3. Подготовить графику и кадры

Для объяснения связей — отдельные схемы SVG с читаемыми подписями. Для интерфейса и результатов — реальные PNG, обрезанные до смысловой области. Исторические снимки либо подписать как исторические, либо переснять актуальное состояние. Изображения, исходный размер которых заставляет уменьшать текст до нечитаемого, заменить крупным фрагментом или несколькими последовательными кадрами.

Сохранять оригиналы. Производные кадры готовить отдельно, например в `images/team-ai-enablement/` после согласования. Изменение исходных PNG и удаление дублей в план не входят. На текущем этапе этот каталог не создавался.

### 4. Вставлять по одному согласованному материалу

Сначала предпросмотр изображения, подписи и места в статье; затем внесение по валидации владельца. Предусмотреть alt-текст, раскрытие оригинала и мобильную последовательность. Планируемый слой «владелец рефлексии» визуально отделить и подписать «не реализовано».

### 5. Проверить итог

Проверить статью в реальном браузере на desktop и мобильном экране: читаемость надписей без обязательного увеличения, отсутствие горизонтального переполнения, правильные ссылки/подписи, соответствие изображений согласованным утверждениям. После проверки отдельно выполнить согласованную публикацию. В этом исследовании изображения в сайт не вставлялись, layout-тесты новой вёрстки не запускались.

## Что из navigator.html сейчас не переносить в работу статьи

Пять его заглушек относятся к провайдеру, панели агента, подтверждению GitLab push, ответу настройки PlantUML и превью. Это отдельный backlog навигатора, а не обязательные картинки статьи. Полезен сюжет самой панели/навигации; все инструкции по ключам и установке переносить не требуется.

Владелец подтвердил 27.10.2026: все переменные в навигаторе синтетические, включая кадры .env; ограничений повторного использования по секретности нет. Эти кадры не включены в первую очередь по смысловой уместности. Числовой график экономии токенов (V13) отложен до наличия исходных данных; временные ряды по одному заявленному эффекту не создаются.
