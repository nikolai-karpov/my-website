## Как использовать

1. Для HR-ответов и карьерных задач сначала читать этот файл, затем:
   - `docs/resume.md`
   - `docs/for-website-cases.md`
   - `index.html`
   - `site-pages/`
   - `cases/warehouse_logistic/`
2. Не придумывать опыт, метрики, стеки и внедрения. Если факт есть только со слов пользователя в текущей сессии, явно помечать его как требующий подтверждения.
3. Для hh/HR-ботов писать коротко, по-русски, без пафоса и без англицизмов, если они не нужны для точного названия технологии.
