# 🚀 Быстрый старт - Просмотр сайта

## Способы запуска локального сервера

### Способ 1: Через Command Palette (рекомендуется)

1. Нажмите `Cmd+Shift+P` (macOS) или `Ctrl+Shift+P` (Windows/Linux)
2. Введите: `Tasks: Run Task`
3. Выберите: **🚀 Запустить локальный сервер**
4. Браузер откроется автоматически на `http://localhost:8080/index.html`

### Способ 2: Через терминал

```bash
npm run dev
```

Это запустит:
- Live Server на порту 8080
- Автоматическую компиляцию SCSS при изменениях
- Автоматическое обновление браузера

### Способ 3: Только сервер (без компиляции SCSS)

```bash
npm run serve
```

### Способ 4: Через Debug панель

1. Откройте панель Debug (`Cmd+Shift+D` или `Ctrl+Shift+D`)
2. Выберите конфигурацию: **🌐 Запустить локальный сервер**
3. Нажмите кнопку запуска (▶️)

## 📋 Доступные задачи

- **🚀 Запустить локальный сервер** - Полный dev режим (SCSS watch + live-server)
- **👀 Просмотр (только сервер)** - Только live-server без компиляции
- **📦 Собрать проект** - Сборка проекта без запуска сервера

## 🔧 Настройки

Сервер настроен на:
- **Порт:** 8080
- **Корневая папка:** `/Users/nik/my-website`
- **Автоматическое открытие:** `index.html`
- **Hot reload:** Включен

## 💡 Полезные команды

```bash
# Запуск с компиляцией SCSS
npm run dev

# Только сервер
npm run serve

# Сборка проекта
npm run build

# Компиляция SCSS
npm run sass:build
```

## 🌐 URL

После запуска сервера сайт будет доступен по адресу:
- **Главная:** http://localhost:8080/index.html
- **Корень:** http://localhost:8080/

## ⚠️ Примечания

- Убедитесь, что порт 8080 свободен
- Если порт занят, измените его в `.vscode/settings.json`
- Live Server автоматически обновляет страницу при изменении файлов
