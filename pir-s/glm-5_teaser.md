# ПИР-Система: Инвестиционный тизер

## Описание проекта и функционала, на который запрашивается финансирование

---

## 1. Суть проекта

**ПИР-Система** — интеллектуальная операционная система для управления экосистемой проектирования в строительной отрасли. Платформа объединяет инструменты найма, рабочее пространство, технологии искусственного интеллекта и систему управления качеством в едином решении.

### Ключевое позиционирование:
- **Не заменяет** CAD/BIM системы (Autodesk, Renga)
- **Создаёт операционную оболочку**, объединяющую людей, процессы и ИИ в единой экосистеме проектирования
- **Стратегия**: сначала корпоративный сегмент с ИИ-инструментами, затем масштабирование через SaaS-платформу

## 2. Проблема рынка

### Количественные показатели кризиса:

| Проблема | Масштаб | Финансовый ущерб |
|----------|---------|------------------|
| **Кадровый дефицит** | ~30 тыс. инженеров, 45% вакансий незакрыты | Перерасход 10-40% от оборота проекта |
| **Низкое качество документации** | 40% документации требует доработок | 1.6-3.2 млн руб./год на одну управляющую позицию |
| **Разрозненность инструментов** | Нет единой среды для CAD, СЭД, коммуникаций | Риск простоя и репутационные потери |
| **Отсутствие институциональной памяти** | Опыт не формализован, ошибки повторяются | +5-7% бюджета на исправление ошибок |

**Совокупный эффект**: Системная утечка **15-25% потенциальной прибыли**

## 3. Функционал, на который запрашивается финансирование

### 3.1 Приоритет 1: ИИ-Нормоконтроль (месяцы 1-12)

```
Входные документы (ТУ, ГПЗУ, ТЗ)
        ↓
    Автоматический разбор (OCR/NLP)
        ↓
    Выявление противоречий и неполноты
        ↓
    Генерация запросов (в 2 клика)
        ↓
    Проверка соответствия ГОСТ/СНиП/СП
```

| Компонент | Описание | Бизнес-результат |
|-----------|----------|------------------|
| **Входной ИРД (автоматический разбор)** | Анализ ТУ, ГПЗУ, ТЗ, выявление противоречий, генерация запросов в 2 клика | Снижение ошибок на 90% |
| **Мультимодальный анализ** | OCR для чертежей, NLP для текста, CV для схем | Высвобождение 30% времени инженеров |
| **Проверка соответствия** | Контроль актуальности ссылок на ГОСТ/СНиП/СП | Прямая экономия 15-25% от бюджета исправлений |

### 3.2 Приоритет 2: База знаний отрасли (месяцы 1-6)

**Ключевой актив**: Структурированный граф нормативов (ГОСТ, СП, СНиП), шаблонов и типовых ошибок

| Этап | Срок | Результат | Точность |
|------|------|-----------|----------|
| Создание базы знаний | Месяцы 1-6 | Машиночитаемый граф нормативов | 60-70% |
| Интеграция LLM | Месяцы 6-12 | RAG-архитектура поверх базы знаний | 75-85% |
| Полный ИИ | Месяцы 10-12 | Полная автоматизация проверок | 90%+ |

### 3.3 Модуль 2: AI Copilot для инженеров и ГИПов

| Функция | Описание | Ценность |
|---------|----------|----------|
| **База данных проектов** | Ускоренный поиск релевантных решений, онбординг новичков | Ускорение подготовки документов в 3-5 раз |
| **Бюрократические драйверы** | Автогенерация заданий, замечаний, ПЗ, уведомлений | Высвобождение времени на инженерию |
| **Кросс-чекинг разделов** | Выявление коллизий между АР, КР и ИОС | Снижение ошибок координации |
| **Контроль оформления** | Автоматическая проверка по ГОСТ, СПДС | Соответствие стандартам |

### 3.4 Модуль 3: Предиктивная аналитика для руководства

| Компонент | Описание |
|-----------|----------|
| **Дашборды на базе ИИ** | Индекс риска срыва сроков, тепловая карта загрузки команд |
| **Прогнозные модели** | Прогноз бюджета и сроков на основе исторических данных |
| **Интеграция с внешними данными** | Погода, календари, нормативы |

### 3.5 Модуль 4: Маркетплейс (готовое ядро)

| Функция | Статус | Масштаб тестирования |
|---------|--------|---------------------|
| **Система управления подрядчиками** | Валидировано | 700 договоров, 150 подрядчиков |
| **Конструктор смарт-контрактов** | Валидирован | Интегрирован в рабочий процесс |
| **Документооборот с контролем версий** | Валидирован | Полный цикл сдачи-приема |
| **Рейтинговая система (8 метрик)** | Валидирована | 2 года калибровки на реальных данных |
