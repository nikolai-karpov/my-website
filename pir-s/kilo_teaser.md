# Описание проекта и функционала для запроса на финансирование

## ПИР-Система — интеллектуальная операционная система для управления экосистемой проектирования

---

## 1. Описание проекта

### 1.1. Суть проекта

**ПИР-Система** — это комплексная платформа для управления экосистемой проектирования, которая объединяет инструменты найма, рабочее пространство, технологии искусственного интеллекта и систему управления качеством в единой платформе.

Проект решает системную проблему российской отрасли проектирования: дефицит ~30 тыс. инженеров-проектировщиков в сочетании с архаичным, разрозненным управлением процессами приводит к прямым финансовым потерям — системная утечка 15–25% потенциальной прибыли с проекта.

### 1.2. Целевой рынок

| Показатель | Значение | Источник |
|-----------|----------|----------|
| **TAM** (РФ) | 1,1 трлн руб. | ГидМаркет 2024 |
| **SAM** | 328 млрд руб. (30% от TAM) | Экспертные интервью |
| **SOM** (3 года) | 6,56 млрд руб. (2% SAM) | Консервативная оценка |

### 1.3. Ключевые проблемы отрасли, которые решает ПИР-Система:

1. **Кадровый дефицит** — 45% вакансий незакрыты, 65% специалистов не соответствуют требованиям
2. **Низкое качество документации** — 40% требует доработок, до 30% времени инженеров — рутинная проверка
3. **Разрозненность инструментов** — отсутствие единой среды для CAD, СЭД, коммуникаций и контроля
4. **Отсутствие институциональной памяти** — опыт не формализован, ошибки повторяются

## 2. Функционал платформы

### 2.1. Основные модули системы

| Модуль | Функционал | Результат |
|--------|------------|-----------|
| **Биржа труда** | Подбор и верификация исполнителей, рейтинговая система | Сокращение времени найма с 3 недель до 2 дней (10x ускорение) |
| **Рабочее пространство** | Единая среда для управления проектами, документацией и коммуникациями | Устранение разрозненности данных |
| **ИИ-инструменты** | Автоматическая проверка документации, выявление ошибок, предложения по оптимизации | Снижение количества ошибок на 90% |
| **Система управления качеством** | Контроль соответствия стандартам, автоматизированная приёмка работ | Повышение качества документации |
| **База знаний** | Хранение накопленного опыта, типовых решений, лучших практик | Формирование институциональной памяти отрасли |
| **Аналитика** | Сквозная аналитика на всех этапах ПИР | Проактивное управление рисками |

### 2.2. Уникальные конкурентные преимущества

По сравнению с набором инструментов (KYRO + Zepth + Archistar + HR-Tech):

| Критерий | Набор инструментов | ПИР-Система |
|----------|-------------------|-------------|
| Количество систем | 3-5 отдельных платформ + интеграции | **1 единая платформа** |
| Время внедрения | 12-24 месяца | **30 дней** |
| Общая стоимость владения (3 года) | 50-100 млн руб. + интеграции | **80 млн руб.** |
| Измеримый ROI | Сложно | **30% экономии** (доказано в пилоте) |
| Сквозная аналитика | Нет | **Единая картина** процессов |
| Сетевые эффекты | Нет | **Экосистема** подрядчиков |
| Институциональная память | Нет | **База знаний** |

### 2.3. Результаты пилотного внедрения (ГК «ПИРС»)

- **Экономия 30%** от бюджета проектирования
- **Сокращение времени найма** с 3 недель до 2 дней (в 10 раз)
- **Снижение ошибок на 90%**
- Пилот завершён в связи с прекращением деятельности заказчика

## 3. Запрос на финансирование

### 3.1. Объём инвестиций

**120–150 млн рублей** (транши по достижению ключевых вех)

### 3.2. Направление средств

1. **Выкуп доли у основателя (Acquisition of IP):** Компенсация за передачу технологических активов, прав на ПО и уникальных алгоритмов
2. **Операционное развитие (Growth Capital):**
   - Разработка ИИ-ядра (Фаза 1)
   - Обеспечение корпоративных продаж до выхода на самоокупаемость (Фаза 2)

### 3.3. Финансовые прогнозы

| Год | Ключевые цели | Выручка (млн руб.) | EBITDA |
|-----|---------------|-------------------|--------|
| 2026 | Доработка продукта: база знаний, ИИ (Фаза 1) | 0 | -45,4 |
| 2027 | Первый год коммерциализации (Фаза 2) | 0–30 (консерв.) / 95–190 (базовый) | — |
| 2028 | Масштабирование, открытие маркетплейса (Фаза 3) | 120–350 | +30...150 |
| 2029 | Доминирование в сегменте | 445–620 | +145...320 |

### 3.4. Ключевые финансовые показатели

- **Точка безубыточности по денежному потоку:** Q3 2027 (базовый сценарий)
- **Прогнозируемая IRR:** от 35% годовых
- **Срок окупаемости:** 4–5 лет
- **Путь выхода:** Продажа стратегическому инвестору (строительный/IT-холдинг) или подготовка к IPO
