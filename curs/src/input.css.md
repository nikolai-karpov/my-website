**Что делает этот файл:**

1. **Импортирует слои Tailwind** (`base`, `components`, `utilities`) - это обязательная основа
2. **В слое `@layer base`** определяет:
   - Плавную прокроллку
   - Стили для выделения текста
   - Кастомный скроллбар
   - Единые стили для заголовков
   - Стили для ссылок навигации с состояниями

3. **В слое `@layer components`** создает переиспользуемые компоненты:
   - Карточки разных типов
   - Кнопки (primary/secondary)
   - Бейджи для статусов
   - Стили для аккордеона и табов
   - Таблицы с ховер-эффектами
   - Тултипы

4. **В слое `@layer utilities`** добавляет кастомные утилиты:
   - Градиентный текст
   - Многострочное обрезание текста
   - Классы для анимаций
   - Адаптивная сетка
   - Стили для контейнеров Mermaid

5. **Дополнительные стили**:
   - Класс `.content-protected` для защиты контента от копирования
   - Адаптивные правки для мобильных устройств
