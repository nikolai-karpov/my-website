# Интерактивный портфель методологии AI-курса

## 🎯 Цель проекта

Трансформация сложных текстовых методологий (дорожной карты внедрения LLM и технологической карты учебного курса) в наглядное, интерактивное веб-приложение для портфолио. Проект демонстрирует навыки фронтенд-разработки, UX-дизайна и умение работать со сложными данными, представляя их в удобном для изучения формате. Включает интерактивный лидо-генератор для сбора требований на разработку курсов.

## ✨ Ключевые особенности

- **Интерактивная навигация:** Плавная прокрутка к разделам, табы для этапов дорожной карты, аккордеоны для модулей курса.
- **Визуальная презентация сложного контента:** KPI в виде инфографики, схемы процессов, структурированные таблицы с фильтрацией.
- **Интерактивный лидо-генератор:** Расширенная бриф-форма с 5P подходом и дополнительными разделами.
- **Обмен брифом через ссылки:** Пользователи могут делиться своими брифами с помощью уникальных ссылок.
- **Профессиональный UI/UX:** Адаптивный дизайн (mobile-first), современная типографика, продуманная цветовая схема в синих тонах.
- **Фокус на производительность и простоту:** Использование легких технологий без тяжелых фреймворков.
- **Базовая защита контента:** Отключение контекстного меню и выделения текста для усложнения прямого копирования.

## 🛠 Технологический стек (Tech Stack)


|Технология|Назначение|Обоснование выбора|
|:---|:---|:---|
|**HTML5**|Семантическая разметка|Веб-стандарт, основа проекта, максимальная доступность.|

|**Git**|Контроль версий|Обязательный стандарт для контроля изменений.|
|**Lightweight Static Server (optional)**|Просмотр проекта|Например, `live-server` для VS Code — для удобства разработки.|

## 🔄 Новые функции

### Обмен брифом через ссылки
Пользователи теперь могут делиться своими брифами с помощью уникальных ссылок. При завершении заполнения брифа появляется кнопка "Копировать ссылку", которая создает URL с закодированными ответами. При открытии такой ссылки ответы автоматически загружаются в форму.

### Улучшенные уведомления
Добавлена унифицированная система уведомлений с анимациями для лучшего пользовательского опыта.

## 🎨 Дизайн и стили (Design & Styling)

* **Цветовая палитра (Color Palette):**
  * Основной фон: `#ffffff`
  * Основной текст: `#1a1a1a` (ближе к `gray-900`)
  * Акцентный цвет (Primary): `#2563eb` (синий `blue-600` Tailwind)
  * Акцентный цвет (Secondary): `#0ea5e9` (голубой `sky-500` для графиков)
  * Акцентный цвет (Success): `#10b981` (зеленый `emerald-500` для KPI)
  * Фоновый цвет секций: `#f8fafc` (`slate-50`)
  * Цвет границ/разделителей: `#e2e8f0` (`slate-200`)
* **Типографика (Typography):**
  * Основной шрифт: Системный стек (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`).
  * Шрифт для кода: `'SF Mono', Monaco, 'Cascadia Mono', 'Courier New', monospace`.
  * Иерархия: Используется относительная единица `rem`. Глобальный размер шрифта: `16px`.
* **Принципы отзывчивости (Responsive Principles):** Mobile-first подход.
  * Базовые стили: `< 768px`
  * `md:` (таблеты) — `≥ 768px`
  * `lg:` (десктопы) — `≥ 1024px`
* **Компоненты:** Кнопки, карточки, таблицы будут стилизованы с помощью утилит Tailwind для единообразия.
* **Анимации:** Плавные переходы и анимации для улучшения пользовательского опыта.

## 🚀 Инструкция по запуску (Getting Started)

1. **Клонируй и перейди в папку проекта:**

   ```bash
   git clone [url]
   cd ai-course-methodology-portfolio
   ```
2. **Установи зависимости (Node.js и npm должны быть установлены):**

   ```bash
   npm install
   ```
3. **Сгенерируй финальный CSS-файл из Tailwind:**

   ```bash
   npm run build:css
   ```

   *(В `package.json` будет скрипт, который запускает `tailwindcss -i ./src/input.css -o ./css/style.css --minify`)*
4. **Запусти проект:**
   * **Способ A (простой):** Открой файл `index.html` прямо в браузере.
   * **Способ B (рекомендуемый для разработки):** Используй Live Server в VS Code или любой другой статический сервер.

## 📝 Принципы разработки (Development Principles)

* **Именование классов:** Используется утилитарный подход Tailwind CSS. Для кастомных компонентов, требующих уникальных стилей, может применяться префикс `acm-` (от AI Course Methodology) в сочетании с kebab-case (например, `.acm-hero-section`).
* **Организация JS:** Код разбит на ES6-модули по функциональности. Каждый модуль отвечает за свою зону ответственности. Используется `import`/`export`. Глобальные переменные минимизированы.
* **Доступность (A11y):** Обязательное использование семантических тегов (`nav`, `section`, `header`, `main`), ARIA-атрибутов для интерактивных элементов (табы, аккордеоны), корректных цветовых контрастов.
* **Комментарии:** JSDoc-комментарии для основных функций и модулей. Комментарии в коде для сложной или неочевидной логики.
* **Модальность:** Использование модальных окон для увеличения контента (диаграммы, изображения) с возможностью масштабирования.
* **Локальное хранение данных:** Использование localStorage для сохранения прогресса пользователей в формах.
* **Обмен данными:** Реализована возможность делиться брифами через URL с закодированными параметрами.
