**Что содержит этот файл:**

1. **Метаданные** - информация о документе
2. **Этапы дорожной карты** в виде массива объектов:
   - `preproject` - Предпроектное обследование
   - `priority-tasks` - Приоритетные задачи
   - `pilot` - Пилотный этап с детальной разбивкой по неделям
   - `kpi` - Критерии успеха с конкретными метриками
   - `risks` - Риски и меры их снижения

3. **Структурированные данные** для каждой секции:
   - Заголовки, описания, иконки
   - Критерии качества с целевыми показателями
   - Списки активностей для пилотного этапа
   - Оценки вероятности и влияния рисков

4. **Дополнительная информация:**
   - Инструменты LLM с приоритетами использования
   - Состав команды для пилотного проекта

**Формат специально подготовлен** для:
- Легкого рендеринга в табах/аккордеонах
- Создания диаграмм KPI
- Фильтрации и поиска по данным
- Подсветки разных типов информации (риски, задачи, метрики)
