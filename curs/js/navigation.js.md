**Что делает этот модуль:**

1. **Плавная прокрутка:**
   - Обработка кликов по ссылкам навигации
   - Прокрутка к целевым секциям с анимацией
   - Обновление URL hash без перезагрузки страницы

2. **Отслеживание активной секции:**
   - Автоматическое определение видимой секции при прокрутке
   - Обновление активного состояния ссылок
   - Добавление ARIA атрибутов для доступности

3. **Мобильная навигация:**
   - Автоматическое создание кнопки гамбургер-меню
   - Адаптивное меню для мобильных устройств
   - Обработка открытия/закрытия с анимацией
   - Блокировка скролла при открытом меню

4. **Клавиатурная навигация:**
   - Навигация между ссылками стрелками
   - Поддержка Home/End клавиш
   - Прокрутка секций PageUp/PageDown
   - Обработка Enter/Space для активации ссылок

5. **Дополнительные функции:**
   - Визуальная обратная связь при кликах
   - Динамическое обновление навигации
   - Создание breadcrumbs (хлебных крошек)
   - Вспомогательные функции для работы с секциями

6. **Оптимизация:**
   - Дебаунс обработчиков скролла
   - Эффективное управление DOM
   - Очистка обработчиков при обновлении

**Ключевые особенности:**
- Полная поддержка доступности (ARIA)
- Адаптивный дизайн для всех устройств
- Оптимизация производительности
- Модульная архитектура
- Подробная обработка ошибок

**Использование в `main.js`:**
```javascript
import { initializeNavigation } from './navigation.js';

// Инициализация при загрузке
initializeNavigation(document.querySelectorAll('.nav-link'));
```
