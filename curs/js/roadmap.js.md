**Что делает этот модуль:**

1. **Динамическое создание табов:**
   - Создание навигации с иконками и заголовками
   - Генерация панелей контента для каждого этапа
   - Адаптивный дизайн для мобильных устройств

2. **Специализированные компоненты для каждого типа этапа:**
   - **Предпроектный этап:** Таблицы критериев, карточки целей
   - **Приоритетные задачи:** Карточки задач с критериями качества
   - **Пилотный этап:** Таймлайн с элементами на временной шкале
   - **KPI:** Сетка метрик с целевыми показателями
   - **Риски:** Карточки рисков с мерами снижения

3. **Интерактивные элементы:**
   - Плавное переключение между табами
   - Анимации появления контента
   - Тултипы с дополнительной информацией
   - Клавиатурная навигация (стрелки, Enter, Tab)
   - Автоматическая прокрутка на мобильных

4. **Доступность (ARIA):**
   - Правильные роли (tablist, tab, tabpanel)
   - Управление с клавиатуры
   - Состояния aria-selected
   - Подписи для скринридеров

5. **Вспомогательные функции:**
   - Получение активного этапа
   - Переключение на конкретный этап
   - Создание тултипов
   - Управление цветовой схемой

**Ключевые особенности:**
- Модульная архитектура с чистыми функциями
- Оптимизация производительности при рендеринге
- Полная поддержка мобильных устройств
- Интеграция с Tailwind CSS классами
- Расширяемая структура для новых типов этапов
