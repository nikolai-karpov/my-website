**Что делает этот файл:**

1. **Основной класс `App`** - централизованное управление приложением:
   - Инициализация всех модулей
   - Загрузка данных
   - Координация работы компонентов

2. **Защита контента (основная функция):**
   - Отключение контекстного меню (правый клик)
   - Блокировка выделения текста
   - Защита от горячих клавиш (Ctrl+C, Ctrl+U, F12, Ctrl+Shift+I)
   - Блокировка копирования/вставки/вырезания
   - Отключение перетаскивания изображений

3. **Загрузка данных:**
   - Асинхронная загрузка `roadmap.json` и `techmap.json`
   - Обработка ошибок загрузки

4. **Инициализация модулей:**
   - Последовательная инициализация всех JS-модулей
   - Передача данных между модулями

5. **Дополнительные функции:**
   - Кнопка "Наверх" при прокрутке
   - Автоматическое обновление активной навигации
   - Анимации появления контента
   - Обработка ошибок с пользовательским интерфейсом

6. **Событийная модель:**
   - Отправка кастомных событий (`app:ready`, `config:changed`)
   - Подписка на события DOM

7. **Конфигурация:**
   - Централизованное управление настройками
   - Возможность включения/отключения защиты контента
   - Режим отладки через параметр URL `?debug=true`

**Ключевые особенности:**
- Модульная архитектура (ES6 модули)
- Graceful degradation при ошибках
- Пользовательские уведомления о защите контента
- Поддержка асинхронных операций
- Легкая расширяемость
