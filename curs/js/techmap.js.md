**Что делает этот модуль:**

1. **Аккордеон модулей курса:**
   - Интерактивное раскрытие/закрытие модулей
   - Анимации перехода
   - Поддержка клавиатурной навигации
   - Автоматическое закрытие других модулей при открытии нового

2. **Детализированные карточки тем:**
   - Структурированное отображение целей обучения
   - Списки создаваемых артефактов
   - Используемые инструменты с бейджами
   - Формат проведения занятий

3. **Система поиска и фильтрации:**
   - Поиск по всем текстовым полям курса
   - Фильтрация по инструментам
   - Сообщения об отсутствии результатов
   - Кнопки сброса и управления

4. **Визуальные элементы:**
   - Цветовая кодировка модулей
   - Иконки для разных типов информации
   - Бейджи с мета-информацией
   - Градиентные фоны и тени

5. **Дополнительные функции:**
   - Получение активного модуля
   - Переключение на конкретный модуль
   - Статистика курса (модули, темы, инструменты)
   - Управление состоянием аккордеона

**Ключевые особенности:**
- Полная доступность (ARIA, клавиатурная навигация)
- Адаптивный дизайн для всех устройств
- Оптимизированная производительность при фильтрации
- Модульная архитектура с чистыми функциями
- Интеграция с Tailwind CSS

**Визуальная структура каждого модуля:**
1. Заголовок с номером, иконкой и названием
2. Информация о длительности и количестве тем
3. Сетка карточек тем с детальной информацией
4. Секция результатов обучения
5. Панель фильтров и поиска над всем аккордеоном
