**Что содержит этот файл:**

1. **Функции работы с данными:**
   - `loadData()` - загрузка JSON файлов
   - `cloneObject()` - клонирование объектов
   - `getNestedValue()` - безопасное получение вложенных свойств
   - `filterArray()` - фильтрация по нескольким полям
   - `groupBy()` - группировка массива по ключу

2. **Функции форматирования:**
   - `formatNumber()` - форматирование чисел с разделителями
   - `formatPercent()` - форматирование процентов
   - `formatDate()` - форматирование дат
   - `truncateText()` - обрезка строк

3. **Функции DOM манипуляций:**
   - `createElement()` - создание элементов с атрибутами
   - `smoothScrollTo()` - плавная прокрутка
   - `isElementInViewport()` - проверка видимости элемента
   - `sanitizeHTML()` - очистка HTML

4. **Утилиты производительности:**
   - `debounce()` - дебаунс функций
   - `throttle()` - троттлинг функций

5. **Вспомогательные функции:**
   - `generateId()` - генерация уникальных ID
   - `storage()` - работа с localStorage
   - `isValidEmail()` - валидация email
   - `getColorClasses()` - получение классов Tailwind по типу
   - `createProgressBar()` - создание progress bar

6. **Экспорт:**
   - Именованный экспорт всех функций
   - Дефолтный экспорт объекта со всеми функциями

**Ключевые особенности:**
- Все функции чистые (pure functions)
- Подробная JSDoc документация
- Обработка ошибок на каждом уровне
- Поддержка TypeScript через JSDoc типы
- Оптимизировано для производительности

**Использование в `main.js`:**
```javascript
import { loadData, createElement, smoothScrollTo } from './utils.js';
```
