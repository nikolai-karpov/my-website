## 1. Продукт и позиционирование

**Кто:** частный эксперт — «Архитектор · Бизнес-аналитик · Интегратор» ИИ-систем для
крупного B2B и промышленности (один человек закрывает три функции).
**Сайт:** https://nikolai-pir-s-ru.sourcecraft.site/portfolio/

**Услуги:** аудит готовности к ИИ; проектирование мультиагентных ИИ-систем (RAG,
multi-agent, guardrails); псевдонимизация/обезличивание данных для безопасной работы
с LLM; промпт-инжиниринг; интеграция (REST/GraphQL); ИИ-ассистент руководителя
(транскрибация встреч, протоколы, контроль задач); n8n-пайплайны.

**Боли клиента:** пилоты не доходят до production; служба ИБ блокирует идеи; утечки
КТ/ПД при работе с облачными LLM; нет измеримого ROI; «ИИ-проекты ломаются на стыке»
бизнеса, инженеров и ИБ.

**ICP:** промышленные холдинги, крупные корпорации со сложными процессами (ERP, ЭДО,
BPMN) и жёсткими требованиями ИБ к защите КТ и ПД.

## 3. Мифы — НЕ использовать в объявлениях (рынок считывает как хайп)

Подтверждено несколькими источниками (Habr/Альпина, Forbes, Gartner):
- **95% корпоративных ИИ-пилотов** не дают измеримого эффекта на P&L; до прода доходят
  лишь **7–10%**. → не обещать «революцию» и «вау-эффект».
- **70–80% проблем качества — это данные**, а не «GPT vs Claude». → не продавать «лучшую модель».
- Реальная пропорция успеха: **10% технологии / 20% данные / 70% люди и процессы**. →
  не позиционировать как «коробочное чудо».
- Стоп-слова в текстах: «революция», «заменит сотрудников», «трансформирует всё»,
  абстрактный «рост эффективности».

**УТП для объявлений:** «доводим пилот до production», «реальный ROI», «сначала данные
и ИБ — потом модель», «работа в закрытом контуре, без утечек», «без хайпа».

## 4. Спрос: главный вывод

Точная ниша («внедрение ИИ в бизнес/компанию/производство») имеет **слабый прямой
спрос** (см. `01_demand_analysis.md`): «внедрение ии в бизнес» — 310, «внедрение ии в
компанию» — 235, «внедрение ии в промышленность» — 43, «специалист по внедрению ии» —
64. Это **рынок с несформированным спросом на точную нишу**.

При этом **широкая категория мощная**: «внедрение искусственного интеллекта» — 2315,
«ии для бизнеса» — 1763, «автоматизация бизнес процессов» — 1353, «нейросети для
бизнеса» — 652, «обезличивание данных» — 872, «rag система» — 747, «мультиагентные
системы» — 749, «цифровой сотрудник» — 1104.

**Следствие для CPA:** берём максимальный охват по широкой категории + горячее
точечное ядро ниши (даже при near-zero частоте — дёшево ловит зарождающийся спрос).
РСЯ и контент-маркетинг под несформированный спрос — вне scope этой задачи (Поиск).

## 5. Структура ядра (тиеры)

- **HOT** — точная ниша «внедрение/интеграция ИИ в бизнес» + коммерческие
  («заказать», «под ключ», «услуги внедрения», «стоимость»). Берём всё, включая
  near-zero — это самый горячий и точный интент.
- **WARM** — широкая категория («ии для бизнеса», «нейросети для бизнеса»,
  «автоматизация бизнес-процессов») + ICP-кластер ИБ (обезличивание для LLM, закрытый
  контур, безопасное внедрение LLM) — главный дифференциатор.
- **ADJACENT** — смежные сегменты: ИИ-ассистент руководителя / транскрибация встреч,
  чат-боты по базе знаний, RAG, мультиагентные системы, RPA, предиктивная аналитика,
  документооборот с ИИ.

## 6. Стратегия по модели оплаты (CPA — выбрана)

**За конверсию (CPA):** нерелевантный трафик бесплатен → берём **максимальный охват**,
включая широкие ВЧ-кластеры. Минусуем **только мусорные лиды** — тех, кто заполнит
форму, но не купит: **соискатели** (вакансия, резюме, зарплата), **студенты**
(курс, обучение нейросетям, научиться), **халявщики** (бесплатно, скачать). Жёсткая
кросс-минусовка и инфо-минусы (что такое, закон, история) при CPA **вредны** — режут
охват и тормозят автостратегию. Инфо-интент не заполняет форму → он бесплатен, не минусуем.

Для гибкости в комплекте также подготовлен **CPC-набор** (узкое ядро + жёсткая
минусовка нерелеванта) — на случай смены модели оплаты.

## 8. Рекомендации по запуску

1. Разнести на группы по тиерам (HOT / WARM-категория / WARM-ИБ / ADJACENT) — разные
   ставки и тексты. Высокая ставка на ICP-кластер ИБ (меньше конкуренция, точный ЛПР).
2. В объявлениях — прагматика и production (см. §3), без хайп-слов.
3. Бренды конкурентов (Secret Agents, ZeBrains, R77, Just AI и т.д.) — **отдельная**
   кампания (перехват) или в минус общей кампании, чтобы не сливать бюджет на чужой
   навигационный спрос. В CPA-ядро бренды не включены.
4. Цель Метрики `form_submit` уже настроена (Formspree-форма) — используем как
   конверсию для автостратегии «Оплата за конверсию».
