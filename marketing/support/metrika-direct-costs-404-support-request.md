# Support Request: Metrika direct_clients 404 For Five Counters

Здравствуйте.

Мы настраиваем read-only мониторинг рекламных кампаний Яндекс.Директ +
Яндекс.Метрика для пяти проектов. Во всех проектах стратегия одинаковая:
оплата за цель Метрики `Отправка формы` / `form_submit`.

При попытке получить связку счётчика Метрики с клиентами Директа наш
инструмент обращается к Management API:

```text
GET https://api-metrika.yandex.net/management/v1/counter/<counter_id>/direct_clients
```

По всем пяти счётчикам API возвращает HTTP 404 Not Found.

## Проверяемые проекты

| Project | Direct CampaignId | Metrika CounterId | TurboPage / landing id |
|---|---:|---:|---:|
| PIR-System | 710380437 | 109570304 | 10000150167 |
| Anonymizer | 710496114 | 109330246 | 10000141047 |
| AI Assistant | 710220828 | 109426601 | 10000146135 |
| Investor Search | 707287188 | 106746847 | в локальной конфигурации отсутствует |
| Portfolio | 710568666 | 109350250 | 10000154536 |

## Пример ошибки

```text
HTTP 404 Not Found
URI: http://api-metrika.yandex.net/management/v1/counter/109350250/direct_clients
```

Такая же ошибка повторяется для счётчиков:

```text
109570304
109330246
109426601
106746847
109350250
```

## Что хотим понять

1. Актуален ли endpoint
   `/management/v1/counter/<counter_id>/direct_clients` для получения
   Direct-клиентов, связанных со счётчиком Метрики?
2. Если endpoint устарел или недоступен, какой актуальный способ API
   использовать для связки Direct campaigns с Metrika ad cost / visits /
   conversions?
3. Нужны ли дополнительные права OAuth-токена, роль пользователя или настройка
   в интерфейсе Метрики/Директа, чтобы этот метод работал?
4. Может ли 404 означать, что у счётчиков не подключены клиенты Директа, или
   это именно ошибка URL/метода?
5. Можно ли вместо чтения `direct_clients` безопасно передавать
   `direct_client_logins=<наш Direct login>` напрямую в отчёт Метрики
   `ym:ad:*`? Будет ли это эквивалентно связке счётчика с Direct-клиентом?
6. Для стратегии “оплата за цель `Отправка формы`” какой рекомендуемый API-путь
   для построения отчёта:
   - расход по CampaignId;
   - достижения конкретной цели Метрики;
   - CPA = расход / достижения цели?
7. Если Direct campaigns ведут на TurboPages / лендинги Директа, есть ли
   отдельный API для получения заявок/lead forms по TurboPageId, или достаточно
   использовать достижения цели `Отправка формы` в Метрике?

Нам важно не считать пропущенные данные нулём. Сейчас из-за 404 мы помечаем
Direct-Metrika bridge как `api_error`. Лиды считаем отдельно по достижениям
цели Метрики `Отправка формы`; если достижений цели нет, это считается
фактическим нулём, а CPA остаётся неопределённым до первой заявки. Нам нужно
понять корректный API-путь для связки расходов Директа, визитов Метрики и
достижений конкретной цели.
