## 1. Контекст и главная проблема

На сайте **нет формы захвата заявки**. Все CTA («Полная форма заявки», «Обсудить проект» и т.п.) ведут на три ссылки-канала: Email (`mailto:`), Telegram, MAX. Тега `<form>` нет нигде, поэтому в Метрике нечего ловить как «отправку заявки».

**Следствие для Яндекс.Директа:**
- Нет «тяжёлой» макро-конверсии → автостратегиям (оплата за конверсии, оптимизация заявок) не на чем обучаться.
- Клик по `mailto:`/Telegram — это намерение, а не факт обращения (открыл приложение ≠ написал). Данные для оптимизации низкого качества.
- Кнопка «Полная форма заявки» ведёт на страницу без формы → прямая потеря лида.

**Решение:** добавить настоящую форму заявки с отправкой через **Formspree** (внешний приёмник, т.к. сайт статический и своего бэкенда нет) и завести цель `form_submit` как ключевое действие.

## 2. Что уже настроено (используем как есть)

Цели через `data-goal` (механизм делегации в `assets/js/main.js`):

| Цель | Событие |
|------|---------|
| `contact_email` | клик по email |
| `contact_telegram` | клик по Telegram |
| `contact_max` | клик по MAX |
| `case_contact` | клик по CTA на странице кейса |

Эти цели остаются — переводим их в разряд **микроконверсий**.

## 3. Задачи маркетолога

### 3.1. Завести аккаунт и форму в Formspree
1. Зарегистрироваться на formspree.io, создать новую форму (New Form).
2. Указать email получателя заявок (`i@nikolai-karpov.ru`).
3. Скопировать endpoint вида `https://formspree.io/f/XXXXXXXX` и передать программисту (см. ТЗ программиста, Задача 1).
4. Включить защиту от спама (reCAPTCHA/honeypot) в настройках формы.
5. (Опционально) Настроить автоответ отправителю и уведомление в Telegram через интеграции Formspree.

### 3.2. Создать цели в Яндекс.Метрике
Метрика → счётчик `109350250` → **Цели** → **Добавить цель** → тип **JavaScript-событие**:

| Название цели | Идентификатор | Тип |
|---------------|---------------|-----|
| Отправка заявки (форма) | `form_submit` | **макро / ключевое действие** |
| Открытие кейса: ПИР-Система | `view_case_pir_s` | микро |
| Открытие кейса: Псевдонимайзер | `view_case_pseudonymizer` | микро |
| Открытие кейса: Аудит холдинга | `view_case_holding_audit` | микро |
| Открытие кейса: AI-ассистент | `view_case_ai_assistant` | микро |
| Открытие кейса: HR n8n-агент | `view_case_hr_n8n_agent` | микро |
| Открытие кейса: Векторное хранилище | `view_case_vector_store` | микро |
| Открытие кейса: Промпт-инженер R&D | `view_case_rd_prompt` | микро |
| Открытие кейса: Платформа перевозчиков | `view_case_carriers` | микро |
| Открытие кейса: Генератор стратегий | `view_case_prompt_generator` | микро |
| Открытие кейса: Курс AI для инженера | `view_case_course` | микро |

> Идентификатор цели должен **точно совпадать** со строкой в `reachGoal` (регистр важен).

### 3.3. Настроить иерархию целей в Яндекс.Директе
- **Ключевое действие (для оптимизации/ДРР):** `form_submit`.
- **Вспомогательные (ретаргетинг, дообучение):** `contact_email`, `contact_telegram`, `contact_max`, `case_contact`, все `view_case_*`.
- Сегменты ретаргетинга: «открыл канал, но не отправил форму», «смотрел кейсы ≥2», «дошёл до формы, не отправил».

## 4. Рекомендации по усилению конверсии (приоритеты)

| Приоритет | Действие | Эффект |
|-----------|----------|--------|
| 🔴 P0 | Форма заявки + цель `form_submit` | главная макро-конверсия, качество данных для Директа |
| 🟠 P1 | Разметка открытия кейсов (`view_case_*`) | сигналы интереса, сегменты ретаргетинга |
| 🟡 P2 | Добавить телефон `tel:` + цель `contact_phone` | канал для части аудитории |
| 🟡 P2 | Скролл-цель (75%) и время на странице | составные цели, ретаргетинг «вовлечённых» |
| 🟢 P3 | A/B заголовков формы и CTA («Бесплатная 30-мин диагностика») | рост конверсии в отправку |
