# План создания новой главной страницы `index_new.html`

## Контекст и цель

На основе анализа пяти вариантов резюме (`vc/`) и текущей главной страницы `index.html` выявлены следующие проблемы позиционирования:

1. **Слишком общее позиционирование** — «Системное внедрение ИИ» не отражает уникальное сочетание интеграторского опыта, архитектуры AI‑платформ и экспертизы внедрения.
2. **Отсутствие измеримых результатов** — в резюме есть конкретные цифры (7→1 день, −25% затрат, ≥80% F1‑score), но на главной они не показаны.
3. **Слабый акцент на главный кейс** — проектирование co‑pilot’а для ГИПа в рамках платформы pir‑s.ru упоминается в резюме, но на главной странице отсутствует.
4. **Неполный технологический стек** — нет упоминания RAG, Knowledge Graph, Qdrant, n8n, Cursor и других ключевых инструментов.
5. **Lead magnet не соответствует услуге** — абстрактный чек‑лист вместо стратегического аудита ИИ‑готовности.

Цель новой страницы — представить вас как **архитектора AI‑платформ для инженерных отраслей**, который прошёл эволюцию от интегратора ERP‑систем до внедренца ИИ и теперь проектирует гибридные AI‑решения (RAG + Knowledge Graph) для проверки документации и автоматизации процессов.

## Структура новой страницы

1. **Hero‑секция** — обновлённый заголовок и подзаголовок, отражающий эволюцию «интегратор → управляющий цифровой трансформацией → внедренец ИИ».
2. **Блок «Измеримые результаты»** — четыре карточки с ключевыми метриками из вашего опыта.
3. **Три ключевые компетенции** — переработанные карточки:
   - Интегратор и архитектор цифровых платформ
   - Архитектор AI‑решений (RAG + Knowledge Graph)
   - Эксперт по внедрению и управлению изменениями
4. **Главный кейс (co‑pilot для ГИПа)** — акцент на проектировании AI‑системы верификации документации в рамках pir‑s.ru.
5. **Расширенный технологический стек** — добавлены категории AI‑архитектура, Low‑code, инструменты AI‑ассистированной разработки.
6. **Блок «Эволюция экспертизы»** — timeline, показывающий путь 2001–2019 (интегратор ERP), 2019–2024 (управляющий цифровой трансформацией), 2025–н.в. (архитектор AI‑решений).
7. **Lead magnet «Аудит ИИ‑готовности»** — предложение стратегической сессии с дорожной картой на 90 дней.
8. **Футер** — без изменений.
