## А. Рефакторинг страницы кейса

### А0. Защита бюджета — сквозной фреймворк (НОВЫЙ)

Защита бюджета — не одна фича, а многослойная система. Она должна работать на трёх горизонтах: **до запуска** (подготовка), **при запуске** (ограничения), **после запуска** (мониторинг + автокоррекция). Сейчас на странице показан только горизонт «до запуска». Рефакторинг должен добавить остальные.

#### Слой 1 — Подготовка (Pre-launch) — уже есть в Блоке I

| Механизм | Где на странице | Как защищает |
|---|---|---|
| Минус-фразы под модель оплаты | Шаг 5 пайплайна, стр. 207–218 | CPA: мягкий фильтр (32 фразы). CPC: жёсткий фильтр (134 фразы) |
| Проверка минусов на каннибализацию | Шаг 6 пайплайна, стр. 215–218 | Каждое минус-слово сверяется с целевым ядром через Wordstat |
| Структурное разделение CPA/CPC | Кампании 01–04, стр. 222–276 | Широкий охват только под CPA. CPC — только целевое ядро |
| Deep-research конкурентов | Шаг 1 пайплайна, стр. 172–178 | Не даёт запустить кампании в слепую, без понимания рынка |
| Честная оговорка про частотности | Callout, стр. 195–204 | «Частотность Wordstat — это показы, а не покупки» — не даёт обмануться цифрами |

#### Слой 2 — Запуск (Launch-time) — нужно добавить в Блок I

Эти механизмы срабатывают в момент заливки кампаний и не дают бюджету утечь с первой минуты:

| Механизм | Как защищает | Где показать |
|---|---|---|
| **Дневной лимит бюджета** | Кампания не потратит больше N₽/день, даже если автостратегия «разгонится» | В карточках кампаний (roi-grid), строка «Бюджет» |

| **Расписание показов** | Не крутить рекламу в 3 часа ночи, если нет конверсий в это время | Добавить в spec-table или карточки |
| **Минус-площадки в РСЯ** | Если кампания в РСЯ — исключить нецелевые площадки (мобильные игры и т.п.) | Упомянуть в Блоке II (мониторинг) |

#### Слой 3 — Мониторинг (Post-launch) — Блок II (новый)

Это ядро дифференциации: то, чего нет в Директе/Метрике. 16 типов инсайтов (секция В + Г), сгруппированных по частоте срабатывания:

**Ежедневные проверки (автоматические):**

| Инсайт | Что защищает | Сигнал тревоги |
|---|---|---|
| 🔴 Диагноз причины аномалий | Расход +40% за день → почему и что делать | Расход > дневной лимит × 1.3 |
| 🔴 Каскадные эффекты | CTR↓ → QS↓ → CPC↑ → бюджет горит | CTR < baseline −20% вторые сутки подряд |
| 🟡 Разгон автотаргетинга | 50%+ кликов по фразам вне Wordstat | % нецелевых запросов >30% |
| 🟡 Каннибализация | Две кампании воюют за одни и те же фразы | Пересечение >10 фраз между кампаниями |

**Еженедельные проверки:**

| Инсайт | Что защищает | Сигнал тревоги |
|---|---|---|
| 🟡 Усталость креативов | CTR деградирует 3-ю неделю → QS падает → CPC растёт | CTR ↓ >20% от 7-дневной средней |
| 🟡 Разрыв объявление↔лендинг | Высокий CTR + высокий отказ → платим за бесполезные клики | Отказы >70% + среднее время <5 сек |
| 🟡 Demand Ceiling | Льём деньги в насыщенный сегмент, где IS >90% | Impression Share >90% при стабильном бюджете |
| 🟡 Кросс-канальные сигналы | Частота в РСЯ >3.5 → скоро поисковый CTR тоже упадёт | Частота показа >3.5 |

**Ежемесячные проверки:**

| Инсайт | Что защищает | Сигнал тревоги |
|---|---|---|
| 🟡 Intent-структура бюджета | 60% бюджета на upper-funnel → платим за нецелевой интерес | Доля info-intent >50% бюджета |
| 🟡 Упущенный спрос | Wordstat показывает спрос, а кампании его не ловят | Новые кластеры Wordstat без покрытия |
| 🟢 Предиктивная сезонность | Через 2 недели рост спроса, а бюджет не увеличен | Wordstat: +40% к прошлому месяцу |
| 🟢 What-if сценарии | При текущем CPA и бюджете — N конверсий; если +30% бюджета — +M конверсий | Плановый пересмотр |
| 🟢 Бизнес-контекст | CPA выглядит высоко, но средний чек 300 000₽ → CPA = 0.17% — отлично | CPA >5% среднего чека |

#### Слой 4 — Автокоррекция (Automated response) — частично в Блоке II, частично в фазе 3 (крон)

Реакция на инсайты. Не просто «посмотрите», а конкретное действие:

| Триггер | Автоматическое действие | Ручное подтверждение |
|---|---|---|
| Расход > дневной лимит × 1.5 | ⚡ Пауза кампании до выяснения | Нужно (проверить причину) |
| CTR < baseline −30% | 📝 Генерация 2–3 вариантов нового текста объявления | Нужно (выбрать и залить) |
| Нецелевые запросы >30% | 📝 Предложение 5–10 новых минус-фраз | Нужно (проверить на каннибализацию) |
| Отказы >70% | 📝 Сравнение текста объявления с лендингом → отчёт о mismatch | Нужно (исправить лендинг) |
| Пересечение >10 фраз | 📝 Список фраз для минусовки в одной из кампаний | Нужно (выбрать кампанию) |
| Impression Share >90% | 📝 Рекомендация перераспределить бюджет в группы с IS <60% | Нужно |

### А3. Подход к цифрам

**Принцип:** цифры никто не считает. Выравниваем по бо́льшему числу, показываем порядок, не точный подсчёт.

**Многокамповость:** кампаний несколько, постоянно дорабатываются, метрики разные. Показываем характер работы, не статику одной кампании.

**Правила округления:**
- Частотности: «0» / «до 100» / «сотни» / «тысячи» / «десятки тысяч»
- Кол-во фраз: «~100» вместо «95/76» (по бо́льшему набору)
- Минус-фразы: «до 150» вместо «32/134» (по бо́льшему набору)
- Группы: «10+ тематических групп»
- Затравочные фразы: «~150»
- Конкуренты: «~20 источников»

## Б. Страница аналитики (одна, обновляемая)

### Принцип

**Одна HTML-страница на компанию** (`site-pages/marketing-insights.html`), с датой актуализации и выводами на эту дату. Не плодим избыточные страницы — крон-задачи накапливают ежедневный анализ, а страница обновляется при необходимости (раз в неделю / по требованию).

### Механика

1. Крон-задачи складывают ежедневные текстовые отчёты в `~/.hermes/cron/output/` (уже делают это)
2. По расписанию (weekly) или по запросу — агент читает накопленные отчёты за период, генерирует инсайты и обновляет одну страницу
3. Страница перезаписывается целиком — всегда актуальный срез
4. Git push → доступна по URL

### Структура страницы

```
┌──────────────────────────────────────────────┐
│ Заголовок: Аналитика рекламных кампаний      │
│ Дата актуализации: DD.MM.YYYY                │
│ Период анализа: за неделю / за месяц         │
├──────────────────────────────────────────────┤
│ Сводка по кампаниям (одна строка на кампанию)│
│ 🟢/🟡/🔴 + одно предложение — главная       │
│ тенденция                                    │
├──────────────────────────────────────────────┤
│ ИНСАЙТЫ (ядро страницы, см. секцию В)        │
│ ┌──────────────────────────────────────────┐ │
│ │ Инсайт 1: заголовок + данные + вывод    │ │
│ │ (callout-блок, как на pseudonymizer)     │ │
│ └──────────────────────────────────────────┘ │

│ │ Инсайт 2: заголовок + данные + вывод    │ │
```

## В. Инсайты — что мы делаем лучше Директа и Метрики

### Суть позиционирования

Директ показывает ЧТО произошло. Метрика показывает ГДЕ потеряли. Ни одна система не говорит ПОЧЕМУ и ЧТО ДЕЛАТЬ. Это работа ассистента.

Формула ценности:
```
Директ:      ЧТО произошло
Метрика:     ГДЕ потеряли
Ассистент:   ПОЧЕМУ + ЧТО ДЕЛАТЬ + СКОЛЬКО СТОИТ БЕЗДЕЙСТВИЕ
```

### Уникальные возможности ассистента (чего нет в Директ/Метрике)

**1. Склейка трёх систем в один вывод**

Директ видит рекламу. Метрика видит сайт. Wordstat видит спрос. Они не общаются. Ассистент склеивает данные из всех трёх и выдаёт вывод, который ни одна система по отдельности не даст.

Пример: «50 кликов по группе, но 2 сессии не дошли (Метрика). При этом Wordstat показывает нулевой спрос по этим фразам → автотаргетинг разогнан, нужно подтянуть минус-фразы.»

**2. Анализ смысла поисковых запросов (intent-кластеризация)**

Директ показывает список из 200 поисковых запросов. Не кластеризует по смыслу. Ассистент разбивает на intent-группы и показывает структуру бюджета:

«40% бюджета уходит на информационный intent (рефераты, статьи, "что такое"). 35% — коммерческий. 25% — брендовый. → Минусуйте "реферат", "статья", "курсовая" — экономия ~40% бюджета.»

**3. Аномалии с диагнозом причины**

Директ: «расход +40%». Ассистент: «CPC вырос с 15₽ до 21₽ по группе "защита персональных данных". В аукцион вошёл новый рекламодатель — появились показы по фразе, которую раньше никто не покупал. Действие: проверить поисковые запросы, отсортировать по "новые".»

Директ говорит «что». Ассистент — «почему и что делать».

**4. Каннибализация между кампаниями**

Директ управляет каждой кампанией отдельно. Не предупредит о пересечениях:

«Кампания "Ниша-ядро" и "Широкий охват" пересекаются по 12 фразам. При CPA — не критично (бесплатный трафик). Но если переключите одну на CPC — минусуйте пересечение, иначе платите за клик дважды.»

**5. Разрыв «объявление ↔ посадочная страница»**

Директ показывает текст объявления. Метрика показывает отказы. Никто не связывает:

«Объявление "Обезличивание данных для нейросетей" — CTR 3.2% (хорошо), но отказы на лендинге 78%, среднее время 4 сек. Кликают охотно, но не находят ответ → лендинг не объясняет продукт понятно. Это не проблема кампании — это проблема посадочной.»

**6. Упущенный спрос — проактивно**

Директ оптимизирует то, что есть. Не скажет «тут есть спрос, а ты его не ловишь»:

«Wordstat: "ai для маркетинга" — ~600 показов/мес в Москве. В текущих кампаниях этой темы нет. Если продукт покрывает маркетинговые кейсы → добавить группу. Если нет — зафиксировать как зону роста.»

**7. Бизнес-контекст вместо голых метрик**

Директ не знает размер вашей сделки:

«CPA 500₽ выглядит высоко. Но средний чек — 300 000₽. CPA = 0.17% от чека. Для B2B с длинным циклом — отлично. Оптимизировать CPA вниз не стоит — лучше наращивать объём.»

**8. Эффект минус-фраз — ретроспектива**

Директ не расскажет, сработали ли минус-фразы:

«После добавления 30 минус-фраз (неделю назад): показы -25%, но CTR +18% и клики +5%. Минус-фразы отсекают мусор, не трогая целевое. Сработали корректно.»

**9. Каскадные эффекты**

Директ показывает каждую метрику отдельно. Не покажет цепочку: CTR↓ → Quality Score↓ → CPC↑ → бюджет кончается быстрее. Ассистент:

«CTR по группе "обезличивание данных" упал с 2.8% до 1.9% за 2 недели. Следствие: CPC вырос с 18₽ до 27₽ (Quality Score деградировал). При текущем бюджете кампания получит на 35% меньше кликов к концу месяца. Причина: конкурент усилил позицию по тем же фразам. Действие: обновить текст объявления (добавить отстройку) → CTR восстановится → CPC вернётся.»

**10. Предиктивная сезонность**

Директ не прогнозирует, он реагирует. Ассистент — заглядывает вперёд:

«По данным Wordstat за прошлые 3 года: в июле спрос по теме "защита персональных данных" растёт на 40-60% (перед сезоном аудитов ИБ). До пика 2 недели → сейчас время: увеличить ставки, подготовить расширенную кампанию, обновить тексты под сезонный intent.»

**11. Усталость креативов**

Ни Директ ни Метрика не предупредят об этом:

«Объявление в группе "анонимизация для LLM" работает 6 недель без изменений. CTR начал деградировать (неделя 1–4: 3.1%, неделя 5: 2.7%, неделя 6: 2.3%). Тренд ускоряется → через 2 недели CTR упадёт ниже 2%, что ударит по Quality Score. Действие: подготовить 2–3 варианта нового текста, запустить A/B.»

**12. Разгон автотаргетинга**

При CPA-стратегии автотаргетинг может «разгоняться»:

«50% кликов за последнюю неделю пришли по фразам, которых нет в Wordstat (нулевой или единичный спрос). Автотаргетинг расширил охват за пределы целевой семантики. При оплате за конверсию это не критично (бесплатно), но автостратегия учится на нецелевых кликах → качество обучения деградирует. Действие: проверить поисковые запросы, минусовать явный мусор.»

**13. Распределение бюджета по воронке**

Директ не знает что такое «воронка»:

«60% бюджета — upper-funnel (осведомлённость: что такое ПДн, 152-ФЗ), 30% — middle (сравнение, обзоры), 10% — lower (купить, цена, заказать). Для CPA это нормально: широкий охват даёт автостратегии данные для обучения. Но если переключить на CPC — перераспределить 40% бюджета вниз воронки, иначе платите за нецелевой интерес.»

**14. What-if сценарии бюджета**

Ни Директ ни Метрика не дают what-if моделирование:

«При текущем CPA ~500₽ и бюджете 30 000₽/мес → ~60 конверсий. Сценарий A: +30% бюджета → +18 конверсий (при стабильном CPA). Сценарий B: -20% бюджета → -12 конверсий, экономия 6 000₽. Сценарий C: перераспределить бюджет из группы "широкий охват" в "ниша-ядро" → CPA может улучшиться на 15-20% при том же бюджете.»

### Приоритеты (что показывать первым)

1. 🔴 **Каскадные эффекты** — «CTR↓ → QS↓ → CPC↑ → бюджет горит, вот почему и что делать»
2. 🔴 **Диагноз причины** — «расход растёт / конверсии падают, потому что X, действие Y»
3. 🔴 **Разрыв объявление↔лендинг** — «клики есть, конверсий нет, причина на сайте»
4. 🟡 **Разгон автотаргетинга** — «половина кликов по нецелевым фразам, автостратегия учится на мусоре»
5. 🟡 **Усталость креативов** — «CTR деградирует 3-ю неделю, нужен свежий текст»
6. 🟡 **Упущенный спрос** — «Wordstat показывает спрос, кампании его не ловят»
7. 🟡 **Intent-структура бюджета** — «60% бюджета на upper-funnel, а вы продаёте B2B-услугу»
8. 🟡 **Каннибализация** — «кампании пересекаются»
9. 🟢 **Предиктивная сезонность** — «через 2 недели рост спроса, готовьтесь»
10. 🟢 **What-if сценарии бюджета** — «если +30% бюджета → +N конверсий»
11. 🟢 **Бизнес-контекст** — «CPA vs чек, стоит ли оптимизировать»
12. 🟢 **Эффект минус-фраз** — «сработали / переусердствовали»

### Формат каждого инсайта на странице

```html
<div class="callout">
  <div class="callout__label">🔴 Диагноз причины / Кампания X</div>
  CPC вырос с ~15₽ до ~21₽ за неделю по группе
  «защита персональных данных». В аукцион вошёл новый
  рекламодатель — появились показы по фразе, которую
  раньше никто не покупал.
  <br><br>
  <strong>Действие:</strong> проверить поисковые запросы
  (сортировка по «новые»), оценить конкурент.
  <strong>Бездействие стоит:</strong> ~N₽/день перерасхода.
  <br>
  <strong>Автоматически:</strong> ассистент уже подготовил
  5 минус-фраз для изоляции нецелевого трафика —
  <a href="#">проверить перед заливкой</a>.
</div>
```

Каждый инсайт = четыре элемента:
1. **Что произошло** (данные из Директ/Метрики/Wordstat)
2. **Почему** (диагноз — рассуждение, которое не даст ни одна система)
3. **Что делать + цена бездействия** (конкретное действие в рублях)
4. **Автоматический ответ** — что ассистент уже сделал сам (A0, Слой 4)

## Г. Результаты Deep Research (живой поиск, 2026-06-08)

Ниже — данные, подтверждённые поиском в реальном интернете (Tavily API), которые обогащают план и дают количественные ориентиры.

### Г1. Тренды рынка

- Глобальные расходы на digital-рекламу: >$700 млрд в 2026 (StackAdapt, Landingi)
- AI-ассистенты становятся стандартом (Ivy™ от StackAdapt, Vibe от Vendasta, Ryze AI)
- Основной запрос рынка: от дашбордов к действиям — «что делать», а не «что видно»
- Ключевые AI-функции: automated negative keywords, budget protection alerts, cross-account scanning
- Автономные бюджетные агенты — 2-3 года до кросс-платформенной зрелости

### Г2. Конкретные цифры для инсайтов

**Creative fatigue / Усталость креативов:**
- CTR падает на 20-40% к 7-му дню активного показа (get-ryze.ai)
- Средний срок жизни креатива: 3-5 дней (Meta), в поиске дольше — 4-6 недель
- AI может предсказать усталость за 2-3 дня до падения CTR (анализ глубины вовлечения, не только CTR)
- Пороговые значения: CTR ↓>20% от 7-дневной средней, частота >3.5, CPC ↑>25%
- Кросс-канальный сигнал: усталость на TikTok → через 1-2 недели усталость на Facebook (revenuecat.com)

**Quality Score каскад (аналог в Директе):**
- QS 1-3 («плохо»): редко выигрывает аукционы при конкуретных ставках
- QS 8-10 («отлично»): снижает CPC на 40-60% ($2.50→$1.50)
- Порочный круг: низкий QS → меньше показов → меньше данных CTR → ещё ниже ожидаемый CTR → QS падает дальше
- Три компонента QS: expected CTR, ad relevance, landing page experience

**Разрыв объявление↔лендинг:**
- Высокий CTR + высокий отказ = разрыв (message mismatch)
- Каждая секунда задержки загрузки costing conversions
- Несовпадение заголовка объявления и лендинга — главная причина отказов

**Каннибализация кампаний:**
- Неконтролируемая каннибализация увеличивает TACOS до 30% (LinkedIn, Amazon PPC)
- Ключевые индикаторы: ACOS spikes без роста продаж, inconsistent impression share
- Решение: negative keyword matrices, intent-based segmentation

**Автотаргетинг в Директе (обязательный с января 2024):**
- Три категории запросов: целевые, узкие, альтернативные
- «Узкие» могут подбирать нецелевой трафик из-за семантического понимания, отличающегося от человеческого
- Рекомендация: еженедельно проверять отчёт «Поисковые запросы» и минусовать мусор
- Автотаргетинг эффективнее с конверсионными стратегиями + счётчик Метрики

**Сезонность через Wordstat:**
- Вкладка «Динамика» показывает помесячные колебания
- Для прогноза нужно минимум 12 месяцев истории
- Региональные различия существенны (один и тот же запрос — разные объёмы по городам)
- Действия: готовить кампании до пика, повышать ставки, обновлять креативы под сезон

**What-if моделирование бюджета:**
- AI-системы (Aprimo, OmniFunnel) моделируют десятки сценариев аллокации
- Учёт historical performance + market trends + seasonality + competitive dynamics
- Обнаружение скрытых неочевидных корреляций между каналами
- Demand ceiling: модели должны знать «сколько спроса осталось», иначе рекомендовали бы тратить в пустоту (logarithmic.com)

### Г3. Российская специфика (подтверждено)

- Автотаргетинг теперь обязателен во всех поисковых кампаниях Яндекса (с 15 января 2024)
- Мастер отчётов — рекомендованный инструмент для детального анализа
- Интеграция Директ + Roistat для сквозной аналитики — отраслевой стандарт
- Wordstat даёт: сбор ядра, анализ кластеров, динамику сезонности, географию спроса
- Типичные ошибки в Wordstat: неправильно подобраны ключевые запросы, ориентация только на ВЧ, отсутствие минус-слов

### Г5. Новые типы инсайтов (15–16)

**15. Demand Ceiling (потолок спроса)**

«Impression share по группе "защита ПДн" стабильно >90% при дневном бюджете 1000₽. Это потолок: аукцион насыщен, больше бюджета не даст пропорционально больше показов. Бюджет перераспределить в группы с IS <60% — там есть куда расти. Или расширить семантику (новые регионы, новые intent-кластеры).»

*Что даёт:* предотвращает «заливание» денег в насыщенные сегменты, где каждый дополнительный рубль даёт всё меньше отдачи.

**16. Кросс-канальные сигналы усталости**

«Показы в РСЯ по креативу "Обезличивание данных" — частота >4.2 (аудитория видит объявление в среднем 4 раза). При частоте >3.5 вовлечённость падает. В поиске это пока не видно (разные аукционы, разная аудитория), но через 1-2 недели усталость перекинется и на поисковую выдачу. Действие: обновить креатив для РСЯ сейчас, не дожидаясь падения поискового CTR.»

*Что даёт:* использует сети как ранний индикатор для поиска, предупреждает до того, как проблема станет видна в основных кампаниях.
