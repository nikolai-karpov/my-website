## Порядок согласования

1. Прочитать `brief.md` → подтвердить или уточнить формулировки продукта и измерители.
2. Прочитать `research/02-audience.md` → подтвердить три сегмента ЦА.
3. Прочитать `research/03-market.md` → сверить, не упущены ли прямые конкуренты.
4. Прочитать `research/04-usp-differentiators.md` → выбрать 3–5 ключевых дифференциаторов, которые пойдут на лендинг.
5. Прочитать `structure-proposal.md` → согласовать блоки лендинга.
6. После согласования — переход к производству: тексты, дизайн, сборка HTML/CSS, UTM, измеримость.

- `docs/career-profile.md` — карьерное позиционирование (verified source of truth)
